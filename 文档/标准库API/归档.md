# 归档模块 API

模块路径：`归档`

提供 zip/tar 打包、解包与成员列举能力。解包时校验成员路径，拒绝绝对路径与 `..` 穿越，避免归档文件写到目标目录之外。仅依赖 Python 标准库。

## 导入方式

```
从 归档 导入 打包ZIP, 解包ZIP, 列出ZIP, 打包TAR, 解包TAR, 列出TAR
导入 归档
```

## 函数列表

### 打包ZIP

把文件或目录打包为 zip 归档，目录内容按相对路径存放。

**签名**：`打包ZIP(源路径: 文本, 目标路径: 文本) -> 文本`

**参数**：
- `源路径`：待打包的文件或目录
- `目标路径`：生成的 zip 文件位置

**异常**：
- `类型错误`：参数不是文本
- `运行时错误`：源路径不存在、是符号链接或写入失败

---

### 解包ZIP

把 zip 归档解压到目标目录，拒绝路径穿越成员。

**签名**：`解包ZIP(压缩包路径: 文本, 目标目录: 文本) -> 文本`

**异常**：
- `运行时错误`：归档无效、成员路径越界或解压失败

---

### 列出ZIP

列出 zip 归档中的全部成员名称。

**签名**：`列出ZIP(压缩包路径: 文本) -> 列表`

---

### 打包TAR

把文件或目录打包为 tar 归档；压缩可为 `gz`、`bz2`、`xz` 或空值。

**签名**：`打包TAR(源路径: 文本, 目标路径: 文本, 压缩: 文本 = 空) -> 文本`

**异常**：`运行时错误`：压缩方式不合法或写入失败

---

### 解包TAR

把 tar 归档解压到目标目录，拒绝绝对路径与路径穿越成员。

**签名**：`解包TAR(压缩包路径: 文本, 目标目录: 文本) -> 文本`

---

### 列出TAR

列出 tar 归档中的全部成员名称。

**签名**：`列出TAR(压缩包路径: 文本) -> 列表`

---
