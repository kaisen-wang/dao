# 进程模块 API

模块路径：`进程`

提供安全的子进程创建、输出捕获与生命周期管理。命令始终以「程序名 + 参数列表」形式传递，不使用 shell 拼接字符串，避免命令注入风险。仅依赖 Python 标准库。

## 导入方式

```
从 进程 导入 运行命令, 启动命令, 等待进程, 终止进程, 进程通信
导入 进程
```

## 函数列表

### 运行命令

运行子进程并捕获输出，返回含退出码、标准输出、标准错误的结果对象。

**签名**：`运行命令(命令: 文本, 参数: 列表 = 空, 工作目录: 文本 = 空, 超时: 数字 = 空) -> 进程结果`

**参数**：
- `命令`：程序名或可执行文件路径，非空文本
- `参数`：字符串参数列表，默认空列表
- `工作目录`：子进程工作目录，默认继承当前目录
- `超时`：等待秒数，默认不超时

**返回**：`进程结果` 对象，含 `退出码`、`标准输出`、`标准错误`、`成功` 属性

**异常**：
- `类型错误`：参数类型不合法
- `运行时错误`：命令找不到、启动失败或执行超时

**示例**：
```
定义 结果 = 运行命令("python", ["-c", "print(123)"], 超时=5)
如果 结果.成功
    打印(结果.标准输出)
```

---

### 启动命令

启动子进程并立即返回进程对象，不等待其结束。

**签名**：`启动命令(命令: 文本, 参数: 列表 = 空, 工作目录: 文本 = 空) -> 进程对象`

**返回**：`进程对象`，可调用 `等待`、`终止`、`是否运行`、`退出码`、`通信` 等方法

---

### 等待进程

等待子进程结束并返回退出码，可指定超时秒数。

**签名**：`等待进程(进程: 进程对象, 超时: 数字 = 空) -> 整数`

**异常**：`运行时错误`：等待超时

---

### 终止进程

向子进程发送终止信号。

**签名**：`终止进程(进程: 进程对象) -> 空`

---

### 是否运行

判断子进程是否仍在运行。

**签名**：`是否运行(进程: 进程对象) -> 逻辑`

---

### 进程退出码

返回子进程的退出码，若仍在运行则返回空值。

**签名**：`进程退出码(进程: 进程对象) -> 整数 或 空`

---

### 进程通信

向子进程发送数据并读取全部输出，返回「标准输出、标准错误」列表。

**签名**：`进程通信(进程: 进程对象, 输入: 文本 = 空, 超时: 数字 = 空) -> 列表`

**异常**：`运行时错误`：通信超时
