# 路径模块 API

模块路径：`路径`

提供路径拼接、拆分、判断、遍历与通配符匹配能力，兼容不同平台的路径分隔符。仅依赖 Python 标准库。

## 导入方式

```
从 路径 导入 拼接, 取文件名, 取扩展名, 取父目录, 存在, 遍历, 匹配
导入 路径
```

## 函数列表

### 拼接

把多个路径片段拼接为一个路径，绝对路径片段会覆盖之前的相对片段。

**签名**：`拼接(*片段: 文本) -> 文本`

**参数**：
- `片段`：至少一个路径片段

**返回**：拼接后的路径文本

**异常**：
- `运行时错误`：未提供任何片段
- `类型错误`：任一片段不是文本

**示例**：
```
定义 文件 = 拼接("/数据", "日志", "2026.txt")  // "/数据/日志/2026.txt"
```

---

### 取文件名

返回路径最后一段的文件名（含扩展名），目录路径返回末尾目录名。

**签名**：`取文件名(路径: 文本) -> 文本`

---

### 取主名

返回路径最后一段去掉扩展名后的主文件名。

**签名**：`取主名(路径: 文本) -> 文本`

---

### 取扩展名

返回路径最后一段的扩展名（含前导点），没有扩展名时返回空文本。

**签名**：`取扩展名(路径: 文本) -> 文本`

**示例**：
```
取扩展名("归档.tar.gz")  // ".gz"
取扩展名("README")       // ""
```

---

### 取父目录

返回路径的父目录部分，没有父目录时返回空文本。

**签名**：`取父目录(路径: 文本) -> 文本`

---

### 分割

把路径拆分为「父目录」与「文件名」两部分组成的列表。

**签名**：`分割(路径: 文本) -> 列表`

---

### 绝对路径

把路径转换为基于当前工作目录的规范化绝对路径。

**签名**：`绝对路径(路径: 文本) -> 文本`

---

### 规范化

规范化路径，合并冗余分隔符与 `.` / `..` 段。

**签名**：`规范化(路径: 文本) -> 文本`

---

### 相对路径

返回路径相对于起点目录的相对路径，起点省略时相对当前工作目录。

**签名**：`相对路径(路径: 文本, 起点: 文本 = 当前目录) -> 文本`

---

### 存在

判断路径是否存在。

**签名**：`存在(路径: 文本) -> 逻辑`

---

### 是文件 / 是目录

分别判断路径是否指向已存在的文件或目录。

**签名**：`是文件(路径: 文本) -> 逻辑`、`是目录(路径: 文本) -> 逻辑`

---

### 列出

列出目录下的条目名称，按字典序排序返回。

**签名**：`列出(路径: 文本) -> 列表`

**异常**：`运行时错误`：目录不存在

---

### 遍历

递归遍历目录，返回其中所有文件与子目录的完整路径列表。

**签名**：`遍历(路径: 文本) -> 列表`

**异常**：`运行时错误`：目录不存在

---

### 匹配

按通配符模式匹配路径并返回排序后的路径列表，`递归` 为真时启用 `**`。

**签名**：`匹配(模式: 文本, 递归: 逻辑 = 假) -> 列表`

**示例**：
```
匹配("/数据/**/*.txt", 真)  // 递归匹配所有 txt 文件
```
