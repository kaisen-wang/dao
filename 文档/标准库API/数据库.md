# 数据库模块 API

模块路径：`数据库`

封装 Python 标准库 `sqlite3`，为常驻 Agent 提供工单、事件与报告的结构化持久化。零第三方依赖，连接对象受线程锁保护，可在并发 Worker 间共享。

## 导入方式

```
从 数据库 导入 连接
导入 数据库
```

## 函数列表

### 连接

打开或新建指定路径的 SQLite 数据库。

**签名**：`连接(路径: 文本) -> 连接对象`

**参数**：
- `路径`：数据库文件路径，`:memory:` 表示内存数据库

**返回**：SQLite 连接对象，其方法见下表

**异常**：
- `类型错误`：路径不是文本类型
- `运行时错误`：无法打开数据库

**示例**：
```
定义 数据库 = 连接("/var/lib/agent/tickets.db")
数据库.开启WAL()
```

---

## 连接对象方法

| 方法 | 签名 | 说明 |
|------|------|------|
| `执行` | `执行(sql: 文本, 参数=空) -> 整数` | 执行 INSERT/UPDATE/DELETE/CREATE，返回影响行数 |
| `查询` | `查询(sql: 文本, 参数=空) -> 列表` | 返回全部行，每行为「列名→值」的字典 |
| `查询一个` | `查询一个(sql: 文本, 参数=空) -> 字典或空` | 返回第一行，无结果时返回 `空` |
| `提交` | `提交() -> 空` | 提交当前事务 |
| `回滚` | `回滚() -> 空` | 回滚当前事务 |
| `开启WAL` | `开启WAL() -> 文本` | 设置 `journal_mode=WAL`，返回当前模式字符串 |
| `最后行ID` | `最后行ID() -> 整数` | 最近一次 INSERT 的行 ID，无插入时为 0 |
| `关闭` | `关闭() -> 空` | 关闭连接，重复调用安全；关闭后操作抛 `运行时错误` |

**参数绑定**：`参数` 可为列表或元组，使用 `?` 占位符绑定，绝不拼接 SQL 字符串。

**示例：建表与插入**
```
定义 数据库 = 连接("agent.db")
数据库.执行("CREATE TABLE IF NOT EXISTS 工单 (编号 TEXT PRIMARY KEY, 阶段 TEXT)")
数据库.执行("INSERT INTO 工单 (编号, 阶段) VALUES (?, ?)", ["T-001", "排队"])
数据库.提交()
定义 行 = 数据库.查询一个("SELECT 阶段 FROM 工单 WHERE 编号 = ?", ["T-001"])
打印(行["阶段"])
```

**示例：事务回滚**
```
数据库.执行("UPDATE 工单 SET 阶段 = ? WHERE 编号 = ?", ["执行中", "T-001"])
数据库.回滚()
// 阶段仍为「排队」
```

**示例：崩溃恢复前置条件**
```
定义 数据库 = 连接("agent.db")
数据库.开启WAL()
// 重启后重新连接仍可读到已提交数据
数据库.关闭()
```
