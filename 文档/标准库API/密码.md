# 密码模块 API

模块路径：`密码`

提供哈希、HMAC 签名与随机标识原语，常用于 webhook 验签与幂等键生成。仅依赖 Python 标准库。

## 导入方式

```
从 密码 导入 SHA256, HMACSHA256, 验证HMAC
从 密码 导入 MD5, SHA1, SHA512
从 密码 导入 UUID, 随机令牌, 随机字节
导入 密码
```

## 函数列表

### SHA256

计算文本的 SHA-256 摘要。

**签名**：`SHA256(文本: 文本) -> 文本`

**参数**：
- `文本`：待计算摘要的文本，按 UTF-8 编码

**返回**：64 位小写十六进制字符串

**异常**：
- `类型错误`：参数不是文本类型

**示例**：
```
定义 摘要 = SHA256("abc")
// 摘要 = "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"
```

---

### HMACSHA256

使用密钥计算文本的 HMAC-SHA256 摘要。

**签名**：`HMACSHA256(密钥: 文本, 文本: 文本) -> 文本`

**参数**：
- `密钥`：签名密钥
- `文本`：待签名的文本

**返回**：64 位小写十六进制字符串

**异常**：
- `类型错误`：任一参数不是文本类型

**示例**：
```
定义 签名 = HMACSHA256("密钥", 请求体)
```

---

### 验证HMAC

常量时间校验签名是否等于文本的 HMAC-SHA256。签名大小写不敏感，格式非法（非 64 位十六进制）时返回 `假` 而不抛异常。

**签名**：`验证HMAC(密钥: 文本, 文本: 文本, 签名: 文本) -> 逻辑`

**参数**：
- `密钥`：签名密钥
- `文本`：原始文本
- `签名`：待验证的十六进制签名

**返回**：`真` 或 `假`

**异常**：
- `类型错误`：任一参数不是文本类型

**示例**：
```
定义 头部 = 请求.请求头
定义 签名 = 头部["x-hub-signature-256"]
如果 验证HMAC(密钥, 请求.请求体, 签名):
    打印("验签通过")
```

### UUID

生成随机 UUID v4 字符串。

**签名**：`UUID() -> 文本`

**返回**：形如 `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx` 的字符串

**示例**：
```
定义 工单号 = UUID()
```

---

### 随机令牌

生成指定字节数的随机十六进制令牌。

**签名**：`随机令牌(字节数: 整数 = 32) -> 文本`

**参数**：
- `字节数`：随机字节数，默认 32（返回 64 位十六进制字符）

**返回**：随机十六进制字符串

**异常**：
- `类型错误`：字节数不是整数（布尔值亦不接受）

**示例**：
```
定义 令牌 = 随机令牌(16)
```

---

### MD5 / SHA1 / SHA512

计算文本的 MD5 / SHA-1 / SHA-512 摘要，返回小写十六进制字符串。

**签名**：
- `MD5(文本: 文本) -> 文本`，32 位十六进制
- `SHA1(文本: 文本) -> 文本`，40 位十六进制
- `SHA512(文本: 文本) -> 文本`，128 位十六进制

**异常**：`类型错误`：参数不是文本类型

> 安全提示：MD5 与 SHA-1 已不适用于碰撞抵抗场景，仅用于校验和兼容；安全性要求高的场景请使用 SHA256 / SHA512。

---

### 随机字节

生成指定字节数的密码学安全随机字节。

**签名**：`随机字节(字节数: 整数 = 32) -> 字节`

**参数**：
- `字节数`：随机字节数，默认 32

**返回**：`bytes` 类型的随机字节串

**异常**：`类型错误`：字节数不是整数或为负数

**示例**：
```
定义 盐 = 随机字节(16)
```
