# 网络模块 API

模块路径：`网络`

## 导入方式

```
从 网络 导入 请求, 流式请求, 创建服务器
从 网络 导入 URL编码, URL解码
导入 网络
```

> 注意：标准库函数必须用「从…导入」取名字；「导入 网络」绑定的模块字典会过滤掉函数，只保留数据型命名空间。

## 函数列表

### 请求

发送 HTTP 请求。

**签名**：`请求(URL: 文本, 选项: 字典 = {}) -> DaoHttpResponse`

**参数**：
- `URL`：请求的 URL
- `选项`：可选配置字典，支持以下键：

| 键 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `方法` | 文本 | `"GET"` | HTTP 方法 |
| `请求头` | 字典 | `{}` | 请求头 |
| `数据` | 文本 | 空 | 请求体数据 |
| `超时` | 小数 | `30` | 超时秒数 |

**返回**：`DaoHttpResponse` 响应对象

**异常**：
- `运行时错误`：请求失败或超时

**示例**：
```
定义 响应 = 请求("https://api.example.com/data", {
    "方法": "GET",
    "请求头": {"Authorization": "Bearer xxx"}
})
打印(响应.状态码)  // 200
打印(响应.响应体)  // 响应内容
```

### 流式请求

逐行读取 HTTP 响应，每读到一行就回调道语言函数（用于 NDJSON / SSE 等流式接口）。

**签名**：`流式请求(URL: 文本, 选项: 字典, 处理函数: 函数) -> 整数`

**参数**：
- `URL`：请求的 URL
- `选项`：与「请求」相同的配置字典（`方法` / `请求头` / `数据` / `超时`）
- `处理函数`：接收一行原始文本的函数；返回 `假` 可提前终止读取

**返回**：实际读取并回调的行数（空行自动跳过）

**异常**：
- `类型错误`：URL 不是文本、选项不是字典、处理函数不是函数
- `运行时错误`：连接失败、HTTP 4xx/5xx、读取异常（回调里抛出的道语言异常原样传播）

**示例**：
```道
从 网络 导入 流式请求
从 编码 导入 JSON

函数 收到(行)
    定义 块 = JSON.解码(行)
    打印(块["message"]["content"], 结尾="", 刷新=真)
    返回 真

定义 行数 = 流式请求("http://localhost:11434/api/chat", {
    "方法": "POST",
    "请求头": {"Content-Type": "application/json"},
    "数据": JSON.编码({"model": "gemma4:e4b", "messages": 历史, "stream": 真}),
    "超时": 120
}, 收到)
```

> 与「请求」的区别：「请求」一次性 `read()` 完整个响应体；「流式请求」用 `readline()` 边收边回调，配合 `打印(..., 结尾="", 刷新=真)` 可实现打字机效果。完整示例见 `示例/AI对话/流式对话.道`。

### 创建服务器

创建 HTTP 服务器。

**签名**：`创建服务器() -> DaoHttpServer`

**示例**：
```
定义 服务器 = 创建服务器()
服务器.路由("GET", "/你好", 函数(请求)
    返回 {"状态码": 200, "内容": "你好，世界！"}
)
服务器.启动(端口=8080)
```

---

### URL编码

对字符串进行 URL 编码。

**签名**：`URL编码(文本: 文本) -> 文本`

**异常**：`运行时错误`：参数不是文本类型

**示例**：
```
打印(URL编码("你好 世界"))  // "%E4%BD%A0%E5%A5%BD%20%E4%B8%96%E7%95%8C"
```

---

### URL解码

对 URL 编码字符串进行解码。

**签名**：`URL解码(文本: 文本) -> 文本`

**异常**：`运行时错误`：参数不是文本类型

**示例**：
```
打印(URL解码("%E4%BD%A0%E5%A5%BD"))  // "你好"
```

## 自定义类型

### DaoHttpResponse

HTTP 响应对象。

**属性**：

| 属性名 | 类型 | 说明 |
|--------|------|------|
| `状态码` | 整数 | HTTP 状态码 |
| `响应头` | 字典 | 响应头 |
| `响应体` | 文本 | 响应体内容 |

---

### DaoHttpServer

HTTP 服务器对象。

**方法**：

| 方法名 | 签名 | 说明 |
|--------|------|------|
| `路由` | `路由(方法: 文本, 路径: 文本, 处理函数: 函数) -> 空` | 注册路由处理函数 |
| `启动` | `启动(端口: 整数 = 8080) -> 空` | 启动服务器（阻塞） |

**异常**：
- `运行时错误`：端口被占用

**路由处理函数**：接收一个请求字典，返回一个包含 `状态码` 和 `内容` 的字典。

**请求字典**：

| 键 | 类型 | 说明 |
|------|------|------|
| `方法` | 文本 | 请求方法 |
| `路径` | 文本 | 请求路径 |
| `请求头` | 字典 | 请求头 |
| `请求体` | 文本 | 请求体 |
