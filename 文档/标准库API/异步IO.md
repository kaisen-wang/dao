# 异步IO

## 函数

| 函数名 | 参数个数 | 描述 |
| --- | --- | --- |
| 获取事件循环 | 0 | 获取当前事件循环，不存在则创建 |
| 运行 | 1 | 运行协程并返回结果 |
| 获取运行中循环 | 0 | 获取当前正在运行的事件循环 |
| 创建任务 | 1 | 将协程包装为 Task 并调度执行 |
| 当前任务 | 0 | 获取当前正在执行的 Task |
| 全部任务 | 0 | 获取事件循环中所有未完成的 Task |
| 等待 | 可变参数 | 等待可等待对象完成 |
| 等待全部 | 可变参数 | 等待所有任务完成 |
| 等待竞速 | 1 | 竞速等待，返回最先完成的结果 |
| 取消任务 | 1 | 取消一个任务 |
| 睡眠 | 1 | 异步睡眠指定秒数 |
| 超时等待 | 2 | 带超时的等待协程 |
| 超时上下文 | 1 | 创建异步超时上下文 |
| 创建队列 | 可变参数 | 创建异步队列 |
| 创建锁 | 0 | 创建异步锁 |
| 创建信号量 | 可变参数 | 创建异步信号量 |
| 创建条件 | 可变参数 | 创建异步条件变量 |
| 创建事件 | 0 | 创建异步事件 |
| 创建屏障 | 1 | 创建异步屏障 |
| 创建子进程 | 可变参数 | 创建异步子进程 |
| 打开连接 | 2 | 打开异步网络连接 |
| 启动服务器 | 可变参数 | 启动异步TCP服务器 |
| 异步读取文件 | 可变参数 | 异步读取文件内容 |
| 异步写入文件 | 可变参数 | 异步写入文件内容 |
| 是否协程 | 1 | 判断对象是否为协程 |
| 是否协程函数 | 1 | 判断对象是否为协程函数 |
| 是否为Future | 1 | 判断对象是否为 Future |
| 是否为Task | 1 | 判断对象是否为 Task |
| 确保Future | 1 | 将对象包装为 Future |
| 在线程中执行 | 可变参数 | 在线程池中执行同步函数 |
| 屏蔽取消 | 1 | 屏蔽取消操作 |
| 组合等待 | 可变参数 | 组合多个可等待对象 |
