# 大模型模块 API

模块路径：`大模型`

为「常驻研发协作 Agent」提供与后端无关的大模型调用接口。Python 核心位于 `dao/llm/`，当前内置 Ollama 实现（用于本地 gemma4:e4b 调试），OpenAI / Anthropic 预留骨架（填入 API key 即可用）。业务层只依赖本模块的中文 API，切换后端无需改动业务逻辑。

设计背景与完整架构见《19-大模型接口层.md》。

## 导入方式

```
从 大模型 导入 消息, 创建客户端, 对话
从 大模型 导入 流式对话, 列出模型
导入 大模型
```

## 核心概念

- **提供者（提供者）**：后端名称，当前支持 `ollama`、`openai`、`anthropic`。
- **客户端**：由 `创建客户端` 返回的 Provider 实例，保存 host / model / 超时等配置，供后续调用复用。
- **消息**：对话的最小单位，用 `消息(角色, 内容)` 构造；角色取 `system` / `user` / `assistant` / `tool`。
- **流式回调**：`流式对话` 每收到一个增量块就调用一次传入的函数，回调返回 `假` 可提前终止。

## 函数列表

### 消息

构造一条消息字典（中文键）。

**签名**：`消息(角色: 文本, 内容: 文本) -> 字典`

**返回**：`{"角色": ..., "内容": ...}`

**示例**：
```
定义 提问 = 消息("user", "用一句话解释道语言")
```

---

### 创建客户端

按提供者名称创建客户端实例。

**签名**：`创建客户端(提供者: 文本, 配置字典: 字典) -> 客户端对象`

**参数**：
- `提供者`：`ollama` / `openai` / `anthropic`
- `配置字典`：传给底层 Provider 的配置。Ollama 常用 `host`、`model`、`timeout`；OpenAI / Anthropic 常用 `api_key`、`base_url`、`model`

**异常**：配置非法（如缺少 `api_key`）时抛中文运行时错误

**示例**：
```
定义 客户端 = 创建客户端("ollama", {
    "host": "http://localhost:11434",
    "model": "gemma4:e4b",
    "timeout": 120
})
```

---

### 对话

向客户端发起一次完整对话，返回聚合后的响应。

**签名**：`对话(客户端, 消息列表: 列表, 选项字典: 字典) -> 字典`

**参数**：
- `消息列表`：元素可以是 `消息()` 返回的中文键字典，也可以是 `{"role": ..., "content": ...}` 英文键字典
- `选项字典`：可含 `模型` / `温度` / `最大token`，或对应的英文键 `model` / `temperature` / `max_tokens`

**返回**（中文键）：
```
{
    "内容": 助手回复文本,
    "模型": 实际使用的模型名,
    "角色": "assistant",
    "思考": 模型思考过程（gemma4 支持，无则为空文本）,
    "完成原因": 后端停止原因,
    "用量": {"提示token": n, "生成token": n, "总token": n},
    "成功": 真,
    "原始": 后端原始响应字典
}
```

**异常**：调用失败时**不抛异常**，返回 `{"成功": 假, "错误": 中文错误信息}`。建议调用方先判 `成功`。

**示例**：
```
定义 应答 = 对话(客户端, [消息("user", "你好")], {})
如果 应答["成功"]
    打印(应答["内容"])
否则
    打印(`调用失败：{应答["错误"]}`)
```

---

### 流式对话

逐块接收模型输出，适合长回答与实时显示。

**签名**：`流式对话(客户端, 消息列表: 列表, 回调函数: 函数, 选项字典: 字典) -> 字典`

**回调参数**：每次调用收到一个块字典 `{"内容": 增量文本, "思考": 增量思考, "完成": 布尔}`；返回 `假` 可提前终止。

**返回**：与 `对话` 相同的中文键响应字典，`内容` 为累积全文。

**示例**：
```
函数 收块(块)
    打印(块["内容"], 结尾="", 刷新=真)
    // 返回 真 继续；返回 假 提前结束
    返回 真

定义 应答 = 流式对话(客户端, [消息("user", "写一首短诗")], 收块, {})
打印(`\n共生成 {应答["用量"]["生成token"]} token`)
```

---

### 列出模型

返回当前后端可用的模型名列表。

**签名**：`列出模型(客户端) -> 列表 | 字典`

**返回**：模型名字符串列表；失败时返回含 `成功`、`错误` 的字典。

**示例**：
```
定义 模型们 = 列出模型(客户端)
遍历 名字 在 模型们
    打印(名字)
```

---

## 错误约定

所有网络 / HTTP / 配置错误在 Python 层统一转换为中文 `LLMError` 子类（`ProviderError` / `ConfigError` 等），桥接层再转换为 `{"成功": 假, "错误": 中文信息}` 返回给道语言。业务代码无需 `尝试/捕获` 底层异常，只需判 `成功` 字段。

## 本地调试

前置条件：本机已启动 ollama 并拉取模型。

```
ollama serve
ollama pull gemma4:e4b
源码/.venv/bin/python 源码/main.py 示例/AI对话/接口层示例.道
```

可选环境变量：`OLLAMA_HOST`（默认 `http://localhost:11434`）、`OLLAMA_MODEL`（默认 `gemma4:e4b`）。
