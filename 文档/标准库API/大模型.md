# 大模型模块 API

模块路径：`大模型`

为「常驻研发协作 Agent」提供与后端无关的大模型调用接口。Python 核心位于 `dao/llm/`，当前内置 Ollama 实现（用于本地 gemma4:e4b 调试），OpenAI / Anthropic 预留骨架（填入 API key 即可用）。业务层只依赖本模块的中文 API，切换后端无需改动业务逻辑。

设计背景与完整架构见《19-大模型接口层.md》。

## 导入方式

```
从 大模型 导入 消息, 创建客户端, 对话
从 大模型 导入 流式对话, 列出模型
从 大模型 导入 工具定义, 工具对话, 工具结果
导入 大模型
```

## 核心概念

- **提供者（提供者）**：后端名称，当前支持 `ollama`、`openai`、`anthropic`。
- **客户端**：由 `创建客户端` 返回的 Provider 实例，保存 host / model / 超时等配置，供后续调用复用。
- **消息**：对话的最小单位，用 `消息(角色, 内容)` 构造；角色取 `system` / `user` / `assistant` / `tool`。
- **流式回调**：`流式对话` 每收到一个增量块就调用一次传入的函数，回调返回 `假` 可提前终止。
- **工具（第三轮新增）**：由 `工具定义` 声明的 OpenAI 风格 tool 字典，交给 `工具对话` 使用；参数模式可用中文键或英文 JSON Schema。
- **工具回调（第三轮新增）**：`工具对话` 每收到一个工具调用就调用一次传入的函数，固定收 2 个参数（工具名称、参数字典），返回值作为工具结果文本回填给模型。
- **最大轮次（第三轮新增）**：`工具对话` 自动循环的上限，正整数，默认 5，用于防止模型与工具互相触发导致死循环。

## 函数列表

### 消息

构造一条消息字典（中文键）。

**签名**：`消息(角色: 文本, 内容: 文本) -> 字典`

**返回**：`{"角色": ..., "内容": ...}`

**示例**：
```
定义 提问 = 消息("user", "用一句话解释道语言")
```

---

### 创建客户端

按提供者名称创建客户端实例。

**签名**：`创建客户端(提供者: 文本, 配置字典: 字典) -> 客户端对象`

**参数**：
- `提供者`：`ollama` / `openai` / `anthropic`
- `配置字典`：传给底层 Provider 的配置。Ollama 常用 `host`、`model`、`timeout`；OpenAI / Anthropic 常用 `api_key`、`base_url`、`model`

**异常**：配置非法（如缺少 `api_key`）时抛中文运行时错误

**示例**：
```
定义 客户端 = 创建客户端("ollama", {
    "host": "http://localhost:11434",
    "model": "gemma4:e4b",
    "timeout": 120
})
```

---

### 对话

向客户端发起一次完整对话，返回聚合后的响应。

**签名**：`对话(客户端, 消息列表: 列表, 选项字典: 字典) -> 字典`

**参数**：
- `消息列表`：元素可以是 `消息()` 返回的中文键字典，也可以是 `{"role": ..., "content": ...}` 英文键字典
- `选项字典`：可含 `模型` / `温度` / `最大token`，或对应的英文键 `model` / `temperature` / `max_tokens`

**返回**（中文键）：
```
{
    "内容": 助手回复文本,
    "模型": 实际使用的模型名,
    "角色": "assistant",
    "思考": 模型思考过程（gemma4 支持，无则为空文本）,
    "完成原因": 后端停止原因,
    "用量": {"提示token": n, "生成token": n, "总token": n},
    "成功": 真,
    "原始": 后端原始响应字典
}
```

**异常**：调用失败时**不抛异常**，返回 `{"成功": 假, "错误": 中文错误信息}`。建议调用方先判 `成功`。

**示例**：
```
定义 应答 = 对话(客户端, [消息("user", "你好")], {})
如果 应答["成功"]
    打印(应答["内容"])
否则
    打印(`调用失败：{应答["错误"]}`)
```

---

### 流式对话

逐块接收模型输出，适合长回答与实时显示。

**签名**：`流式对话(客户端, 消息列表: 列表, 回调函数: 函数, 选项字典: 字典) -> 字典`

**回调参数**：每次调用收到一个块字典 `{"内容": 增量文本, "思考": 增量思考, "完成": 布尔}`；返回 `假` 可提前终止。

**返回**：与 `对话` 相同的中文键响应字典，`内容` 为累积全文。

**示例**：
```
函数 收块(块)
    打印(块["内容"], 结尾="", 刷新=真)
    // 返回 真 继续；返回 假 提前结束
    返回 真

定义 应答 = 流式对话(客户端, [消息("user", "写一首短诗")], 收块, {})
打印(`\n共生成 {应答["用量"]["生成token"]} token`)
```

---

### 列出模型

返回当前后端可用的模型名列表。

**签名**：`列出模型(客户端) -> 列表 | 字典`

**返回**：模型名字符串列表；失败时返回含 `成功`、`错误` 的字典。

**示例**：
```
定义 模型们 = 列出模型(客户端)
遍历 名字 在 模型们
    打印(名字)
```

---

### 工具定义

声明一个可调用工具，返回 OpenAI 风格 tool 字典供 `工具对话` 使用（第三轮新增）。

**签名**：`工具定义(名称: 文本, 描述: 文本 = "", 参数模式: 字典 = 空) -> 字典`

**参数**：
- `名称`：非空文本，工具名（如 `查天气`）。
- `描述`：给模型看的中文用途说明，缺省为空文本。
- `参数模式`：工具参数的 JSON Schema，支持两种写法：
  - 中文键：`{"属性": {"城市": {"类型": "string", "描述": "城市名"}}, "必填": ["城市"]}`；支持映射键 `类型`→`type`、`描述`→`description`、`必填`→`required`、`属性`→`properties`、`条目`→`items`、`枚举`→`enum`。
  - 英文键：标准 JSON Schema `{"type": "object", "properties": {...}, "required": [...]}`。

**返回**：`{"type": "function", "function": {"name": ..., "description": ..., "parameters": ...}}`

**异常**：名称为空或非文本、描述非文本、参数模式非字典时抛中文类型错误。

**示例**：
```
定义 查天气 = 工具定义("查天气", "查询指定城市的天气", {
    "属性": {"城市": {"类型": "string", "描述": "城市名"}},
    "必填": ["城市"]
})
```

### 工具对话

发起**自动多轮**工具对话：模型请求工具 → 调用回调执行 → 把结果作为 `tool` 消息回填 → 再次请求，直到模型不再调用工具或达到「最大轮次」（第三轮新增）。

**签名**：`工具对话(客户端, 消息列表: 列表, 工具列表: 列表, 回调函数: 函数, 选项字典: 字典) -> 字典`

> 固定 **5 个参数**，与 `流式对话` 同为需要解释器上下文的内置函数。

**参数**：
- `客户端`：`创建客户端` 返回的实例，须支持 `chat_with_tools`；不支持时返回失败字典。
- `消息列表`：同 `对话`，元素为中文键或英文键消息字典。
- `工具列表`：元素为 `工具定义` 返回的 tool 字典；也接受中文键字典 `{"名称": ..., "描述": ..., "参数模式": ...}`。
- `回调函数`：固定接受 **2 个参数**——`名称`（工具名文本）、`参数`（已解析的参数字典），返回工具执行结果文本；非文本返回值自动转成文本。回调自身抛异常时转成结果文本「工具执行失败：...」，不中断循环。
- `选项字典`：支持 `最大轮次`（正整数，默认 5）及 `模型`／`温度`／`最大token`（或英文 `model`／`temperature`／`max_tokens`，中文键优先）。`最大轮次` 非正整数时直接返回失败字典「最大轮次必须是正整数」。

**返回**（中文键，成功）：
```
{
    "成功": 真,
    "内容": 最终答复文本,        // 模型不再请求工具时给出
    "工具调用记录": [{"名称": 工具名, "参数": 参数字典, "结果": 回调返回文本}],
    "用量": {"提示token": n, "生成token": n, "总token": n},   // 各轮累计
    "轮次": n
}
```

**返回**（失败：后端不支持／调用失败／达到轮次上限）：
```
{
    "成功": 假,
    "错误": 中文错误信息,
    "工具调用记录": [...],       // 已完成的调用仍会带回
    "用量": {...},
    "轮次": n
}
```
失败时**不含** `内容` 键；调用方应先判 `成功`。

**说明**：Provider 层把各后端 `tool_calls` 归一为英文键 `{"id","name","arguments"}`，桥接层记录为中文键，自动回调模式下无需手工追加 `tool` 消息；手动模式见 `工具结果`。

**示例**：
```
函数 执行工具(名称, 参数)
    如果 名称 == "加法"
        定义 和 = 参数["甲"] + 参数["乙"]
        返回 `结果是 {和}。`
    返回 `未知工具：{名称}`

定义 加法 = 工具定义("加法", "计算两个整数之和", {
    "属性": {"甲": {"类型": "integer"}, "乙": {"类型": "integer"}},
    "必填": ["甲", "乙"]
})

定义 应答 = 工具对话(客户端, [消息("user", "算一下 12 加 30。")], [加法], 执行工具, {"最大轮次": 5})
如果 应答["成功"]
    打印(应答["内容"])
否则
    打印(`工具对话失败：{应答["错误"]}`)
```

### 工具结果

构造一条 `role="tool"` 消息字典，供不用自动回调的高级/手动模式回填工具结果（第三轮新增）。

**签名**：`工具结果(调用编号: 文本, 内容: 文本) -> 字典`

**参数**：
- `调用编号`：模型返回的 `tool_calls` 中的 `id`，对应 `ChatResponse.to_dict()` 里 `工具调用` 记录的 `编号`。
- `内容`：工具执行结果文本。

**返回**：`{"角色": "tool", "内容": ..., "调用编号": ...}`

**异常**：调用编号非文本时抛中文类型错误。

**示例**：
```
定义 回填 = 工具结果("call_0", "北京今天晴，26℃。")
```

---

## 错误约定

所有网络 / HTTP / 配置错误在 Python 层统一转换为中文 `LLMError` 子类（`ProviderError` / `ConfigError` 等），桥接层再转换为 `{"成功": 假, "错误": 中文信息}` 返回给道语言。业务代码无需 `尝试/捕获` 底层异常，只需判 `成功` 字段。

## 本地调试

前置条件：本机已启动 ollama 并拉取模型。

```
ollama serve
ollama pull gemma4:e4b
源码/.venv/bin/python 源码/main.py 示例/AI对话/接口层示例.道
```

可选环境变量：`OLLAMA_HOST`（默认 `http://localhost:11434`）、`OLLAMA_MODEL`（默认 `gemma4:e4b`）。
