# 二进制模块 API

模块路径：`二进制`

提供 struct 定长打包/解包、整数与浮点和字节互转、基于 JSON 类型标签的安全序列化、字节文件读写，以及对 pickle 的显式拒绝与白名单加载。仅依赖 Python 标准库。

**安全约定**：`Pickle解包` 默认拒绝加载任何 pickle 数据；只有显式传入「模块.类名」白名单时才允许加载，且未列入白名单的类会被拦截。日常跨进程/跨语言数据交换请优先使用 `安全序列化`。

## 导入方式

```
从 二进制 导入 定长打包, 定长解包, 计算大小
从 二进制 导入 整数转字节, 字节转整数, 浮点转字节, 字节转浮点
从 二进制 导入 安全序列化, 安全反序列化
从 二进制 导入 写入字节, 读取字节, 序列化到文件, 反序列化自文件
从 二进制 导入 Pickle打包, Pickle解包
导入 二进制
```

## 函数列表

### 定长打包

按 struct 格式字符串把数值打包为定长字节串。

**签名**：`定长打包(格式: 文本, 值: 数值或列表) -> 字节`

**参数**：
- `格式`：struct 格式字符串，如 `>2i`、`d`、`10s`
- `值`：单个数值或数值列表

**异常**：`运行时错误`：格式无效、取值个数不匹配

---

### 定长解包

按 struct 格式字符串把定长字节串解包为数值列表。

**签名**：`定长解包(格式: 文本, 数据: 字节) -> 列表`

**异常**：`类型错误`：数据不是字节；`运行时错误`：长度与格式不匹配

---

### 计算大小

返回 struct 格式字符串对应的字节数。

**签名**：`计算大小(格式: 文本) -> 整数`

---

### 整数转字节

把整数转换为固定长度的字节串。

**签名**：`整数转字节(整数, 长度=4, 字节序="大端", 有符号=假) -> 字节`

**参数**：
- `长度`：目标字节数，必须为正整数
- `字节序`：`大端` 或 `小端`
- `有符号`：是否按补码表示负数

**异常**：`运行时错误`：整数超出指定字节长度

---

### 字节转整数

把字节串转换回整数。

**签名**：`字节转整数(数据: 字节, 字节序="大端", 有符号=假) -> 整数`

---

### 浮点转字节 / 字节转浮点

浮点与 8 字节 IEEE 754 双精度字节串互转。

**签名**：`浮点转字节(浮点, 字节序="大端") -> 字节`；`字节转浮点(数据, 字节序="大端") -> 浮点`

**异常**：`运行时错误`：字节转浮点的输入长度不是 8 字节

---

### 安全序列化 / 安全反序列化

以 JSON 加类型标签的格式序列化数据，仅识别空值、布尔、整数、浮点、文本、字节、列表、元组与字典；反序列化遇到未知标签即拒绝，不会执行任何对象构造逻辑。

**签名**：`安全序列化(数据) -> 字节`；`安全反序列化(数据: 字节) -> 任意`

**示例**：
```
从 二进制 导入 安全序列化, 安全反序列化
定义 原始 = {"姓名": "张三", "列表": [1, 2]}
定义 还原 = 安全反序列化(安全序列化(原始))  // 与原始相等
```

**异常**：`类型错误`：包含不支持的类型或非字符串字典键；`运行时错误`：数据格式无效或含未知标签

---

### 写入字节 / 读取字节

字节文件的读写封装。

**签名**：`写入字节(路径: 文本, 数据: 字节) -> 整数`（返回写入字节数）；`读取字节(路径: 文本) -> 字节`

**异常**：`运行时错误`：文件不存在或读写失败

---

### 序列化到文件 / 反序列化自文件

安全序列化与文件读写的组合操作。

**签名**：`序列化到文件(数据, 路径: 文本) -> 整数`；`反序列化自文件(路径: 文本) -> 任意`

---

### Pickle打包 / Pickle解包

`Pickle打包` 序列化完全可信的数据；`Pickle解包` 默认拒绝任何 pickle 数据，只有提供白名单后才允许加载指定类型。

**签名**：`Pickle打包(数据) -> 字节`；`Pickle解包(数据: 字节, 白名单=空) -> 任意`

**参数**：
- `白名单`：`["模块.类名"]` 形式的文本列表，例如 `["builtins.dict"]`

**异常**：`运行时错误`：未提供白名单（默认拒绝）、类型不在白名单、pickle 数据无效

**示例**：
```
从 二进制 导入 Pickle打包, Pickle解包
定义 数据 = Pickle打包({"键": 1})
// Pickle解包(数据)                       // 抛出运行时错误：拒绝不可信数据
定义 还原 = Pickle解包(数据, ["builtins.dict"])  // 显式白名单后允许
```
