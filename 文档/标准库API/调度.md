# 调度模块 API

模块路径：`调度`

基于后台线程提供延迟与周期调度，用于常驻 Agent 的轮询兜底（60s）、Watchdog 停滞巡检与预算日重置。仅依赖标准库 `threading`，任务线程为 daemon，不阻塞进程退出。

## 导入方式

```
从 调度 导入 延迟执行, 周期执行, 取消调度
从 调度 导入 取消全部, 等待全部
导入 调度
```

## 函数列表

### 延迟执行

一次性定时执行回调，到达指定毫秒数后触发一次。

**签名**：`延迟执行(毫秒: 整数, 回调: 函数) -> 整数`

**参数**：
- `毫秒`：非负整数，延迟时长
- `回调`：道语言函数或 Python 可调用对象，无参数

**返回**：正整数调度 ID，用于取消

**异常**：
- `类型错误`：毫秒为负数、非整数或布尔值；回调不可调用

**示例**：
```
定义 任务号 = 延迟执行(60000, 轮询事件)
// 需要提前取消时：取消调度(任务号)
```

---

### 周期执行

按指定毫秒数周期重复执行回调，直到该调度被取消为止。

**签名**：`周期执行(毫秒: 整数, 回调: 函数) -> 整数`

**参数**：
- `毫秒`：非负整数，周期间隔
- `回调`：道语言函数或 Python 可调用对象，无参数

**返回**：正整数调度 ID

**异常**：同 `延迟执行`

**示例**：
```
定义 巡检号 = 周期执行(1800000, 巡检停滞任务)
// 30 分钟巡检一次；退出前 取消调度(巡检号)
```

---

### 取消调度

取消指定调度 ID 对应的任务。

**签名**：`取消调度(调度ID: 整数) -> 逻辑`

**返回**：成功取消返回 `真`，ID 不存在或任务已完成返回 `假`

**示例**：
```
如果 取消调度(巡检号):
    打印("巡检已停止")
```

---

### 取消全部

取消当前所有待触发或运行中的定时调度任务。

**签名**：`取消全部() -> 空`

**示例**：
```
// 进程退出前的清理
取消全部()
```

---

### 等待全部

阻塞等待，直到所有一次性调度任务执行完毕。

**签名**：`等待全部() -> 空`

**注意**：周期任务不会自动结束，调用前须先 `取消全部()` 或逐个 `取消调度()`，否则会永久阻塞。

**示例**：
```
延迟执行(100, 任务甲)
延迟执行(200, 任务乙)
等待全部()
打印("两个任务都完成了")
```

---

## 回调约定

- 回调为道语言函数时，通过解释器 `call_function` 调用，可正常访问闭包与全局作用域。
- 回调为普通 Python 可调用对象时直接调用，便于测试与嵌入。
- 回调抛出的异常会被捕获并转成中文 `运行时错误` 输出到标准错误，不会污染 stdout，也不会静默终止调度线程。
