# 日志模块 API

模块路径：`日志`

## 导入方式

```
从 日志 导入 配置日志, 默认格式, 创建日志器, 创建文件处理器, 创建控制台处理器
导入 日志
```

> 标准库函数须用 `从 模块 导入 名称` 形式；`导入 日志` 不会导出内置函数。

## 快速开始

```
从 日志 导入 配置日志, 默认格式

日志器 = 配置日志(输出="两者", 路径="应用.log", 格式=默认格式, 级别="信息")
日志器.信息("服务启动", 错误码="E0001", 位置="入口.道:12")
```

`默认格式` 为 `{时间戳} | {级别} | {线程ID} | {代码位置} | {错误码} | {描述信息}`，输出形如：

```
2026-11-27 17:15:03,123 | INFO | 140245328901120 | 入口.道:12 | E0001 | 服务启动
```

## 函数列表

### 配置日志

一步配置日志器：选定输出目标、格式、级别与时间格式，返回可直接使用的日志器。重复配置同名日志器会重置其原有处理器，避免同一条日志被重复写出。

**签名**：`配置日志(名称="道", 输出="控制台", 路径=空, 格式=默认格式, 级别="信息", 时间格式=空) -> DaoLogger`

**参数**：
- `名称`：日志器名称（同名日志器共享配置）
- `输出`：`控制台` / `文件` / `两者`
- `路径`：输出含`文件`时必填，指定日志文件路径
- `格式`：格式字符串，见下方占位符表；默认使用 `默认格式`
- `级别`：`调试` / `信息` / `警告` / `错误` / `致命`
- `时间格式`：strftime 风格时间格式，如 `%Y年%m月%d日 %H:%M:%S`

**异常**：`运行时错误`：输出方式无效、文件输出缺少路径、级别无效

**示例**：
```
从 日志 导入 配置日志
日志器 = 配置日志(输出="文件", 路径="应用.log", 级别="警告")
日志器.警告("磁盘空间不足", 错误码="W002")
```

### 创建日志器

创建一个指定名称的日志器，可选设置默认代码位置。需自行添加处理器才能输出。

**签名**：`创建日志器(名称: 文本, 位置="") -> DaoLogger`

**参数**：
- `名称`：日志器名称
- `位置`：默认代码位置，可用 `设置位置` 后续修改

**示例**：
```
从 日志 导入 创建日志器, 创建控制台处理器
日志器 = 创建日志器("我的应用")
日志器.添加处理器(创建控制台处理器())
日志器.信息("程序启动")
```

---

### 创建文件处理器

创建写入指定路径文件的日志处理器，可单独指定格式与时间格式。

**签名**：`创建文件处理器(路径: 文本, 格式=空, 时间格式=空) -> DaoFileHandler`

**参数**：
- `路径`：日志文件路径
- `格式`：可选，仅作用于本处理器
- `时间格式`：可选，strftime 风格

**异常**：`运行时错误`：无法创建日志文件

**示例**：
```
定义 文件处理器 = 创建文件处理器("app.log", "{时间} {级别} {消息}")
```

---

### 创建控制台处理器

创建输出到控制台（标准错误流）的日志处理器，可单独指定格式与时间格式。

**签名**：`创建控制台处理器(格式=空, 时间格式=空) -> DaoConsoleHandler`

**示例**：
```
定义 控制台处理器 = 创建控制台处理器()
```

## 自定义类型

### DaoLogger

日志器对象，提供分级日志、格式设置与多处理器输出。

**方法**：

| 方法名 | 签名 | 说明 |
|--------|------|------|
| `调试` | `调试(消息, 错误码="", 位置=空)` | 输出调试级别日志 |
| `信息` | `信息(消息, 错误码="", 位置=空)` | 输出信息级别日志 |
| `警告` | `警告(消息, 错误码="", 位置=空)` | 输出警告级别日志 |
| `错误` | `错误(消息, 错误码="", 位置=空)` | 输出错误级别日志 |
| `致命` | `致命(消息, 错误码="", 位置=空)` | 输出致命级别日志 |
| `记录` | `记录(级别, 消息, 错误码="", 位置=空)` | 按中文级别名分派 |
| `设置级别` | `设置级别(级别)` | 设置最低输出级别 |
| `设置位置` | `设置位置(位置)` | 设置默认代码位置，后续日志可省略 |
| `添加处理器` | `添加处理器(处理器)` | 添加输出处理器，同一对象或同一文件不重复添加 |
| `设置格式` | `设置格式(格式, 时间格式=空)` | 设置所有处理器的格式 |

**日志级别**：

| 道语言级别 | 说明 | 数值 |
|-----------|------|------|
| `调试` | 调试信息 | 10 |
| `信息` | 一般信息 | 20 |
| `警告` | 警告信息 | 30 |
| `错误` | 错误信息 | 40 |
| `致命` | 致命错误 | 50 |

**格式占位符**：

| 占位符 | 说明 |
|--------|------|
| `{时间戳}` / `{时间}` | 时间戳（默认 `年-月-日 时:分:秒,毫秒`） |
| `{日志级别}` / `{级别}` | 日志级别（DEBUG / INFO / WARNING / ERROR / CRITICAL） |
| `{线程ID}` | 当前线程 ID |
| `{线程名}` | 当前线程名 |
| `{代码位置}` / `{位置}` | 调用时传入的位置，未传则用 `设置位置` 的默认值 |
| `{错误码}` | 调用时传入的错误码，未传为空 |
| `{描述信息}` / `{描述}` / `{消息}` | 日志正文 |
| `{名称}` | 日志器名称 |
| `{文件名}` / `{行号}` / `{函数名}` | Python logging 原生字段（调试用） |

> 格式中的字面 `%` 会自动转义，可直接写 `完成 100% {消息}`。
> 由于道语言方法调用不携带源码位置，`{代码位置}` 需调用时传入或用 `设置位置` 预设。

**异常**：`运行时错误`：设置无效的日志级别、处理器类型无效

**示例**：
```
从 日志 导入 配置日志, 默认格式
日志器 = 配置日志(输出="文件", 路径="应用.log", 格式=默认格式)
日志器.设置位置("服务.道:20")
日志器.信息("程序启动")
日志器.错误("连接失败", 错误码="E500", 位置="网络.道:88")
日志器.记录("警告", "重试第 2 次", 错误码="W201")
```
