# 国际化模块 API

模块路径：`国际化`

提供区域设置查询与安全封装、文本翻译表注册与查询、复数形式，以及数字/货币/日期本地化格式。仅依赖 Python 标准库 `locale` 与 `datetime`，不引入第三方包。

数字与货币格式使用内置区域格式表（zh/en/de/fr/ja），避免依赖运行环境已安装的区域集；区域查询与设置仍基于标准库 `locale`。

## 导入方式

```
从 国际化 导入 当前区域, 设置区域, 区域别名, 可用区域
从 国际化 导入 注册翻译, 翻译, 翻译项数, 清除翻译
从 国际化 导入 复数形式, 格式化数字, 格式化货币, 格式化日期, 星期名称, 月份名称
导入 国际化
```

## 函数列表

### 当前区域

返回当前进程的区域设置（语言与编码）字典。

**签名**：`当前区域() -> 字典`

**返回**：`{"语言": 文本, "编码": 文本}`，未设置时对应字段为空文本

---

### 设置区域

设置当前进程的全局区域，返回实际生效的区域名；传入空文本可恢复系统默认区域。

**签名**：`设置区域(区域名: 文本) -> 文本`

**异常**：`运行时错误`：区域名不被系统支持

---

### 区域别名

把区域名称规范化为标准别名，不修改全局区域设置。

**签名**：`区域别名(名称: 文本) -> 文本`

**示例**：`区域别名("zh_CN.UTF-8")` → `"zh_CN.UTF-8"`

---

### 可用区域

返回当前系统已知的区域别名列表（按名称排序去重）。

**签名**：`可用区域() -> 列表`

---

### 注册翻译 / 翻译 / 翻译项数 / 清除翻译

翻译表以「语言标识 → 键 → 译文」两级字典保存。查询时依次尝试完整区域（如 `zh_CN`）、语言前缀（`zh`）与调用方提供的默认值；都未命中时返回键本身。

**签名**：
- `注册翻译(语言: 文本, 键: 文本, 文本: 文本) -> 文本`
- `翻译(键: 文本, 语言=空, 默认=空) -> 文本`
- `翻译项数(语言=空) -> 整数`
- `清除翻译(语言=空) -> 整数`（返回删除条目数）

**示例**：
```
从 国际化 导入 注册翻译, 翻译
注册翻译("zh_CN", "hello", "你好")
注册翻译("zh", "thanks", "谢谢")
打印(翻译("hello", "zh_CN"))       // 你好
打印(翻译("thanks", "zh_CN"))       // 谢谢（回退到语言前缀）
打印(翻译("缺失", "fr", 默认="缺省")) // 缺省
```

---

### 复数形式

根据数量与语言返回单数或复数形式；中文、日文、韩文始终返回单数形式，其余语言在数量不等于 1 时返回复数形式。

**签名**：`复数形式(数量: 数值, 单数: 文本, 复数=空, 语言=空) -> 文本`

**说明**：未提供复数形式时，非中文语言自动在单数后加 `s`。

---

### 格式化数字 / 格式化货币

按区域规则加入千位分组符号与本地化小数点。zh/en 使用 `,` 与 `.`，de 使用 `.` 与 `,`，fr 使用空格与 `,`。

**签名**：
- `格式化数字(数值, 语言=空, 分组=真) -> 文本`
- `格式化货币(数值, 符号=空, 语言=空) -> 文本`

**示例**：
```
打印(格式化数字(1234567.5, "de"))     // 1.234.567,5
打印(格式化货币(12.5, 语言="en"))     // $12.5
```

---

### 格式化日期 / 星期名称 / 月份名称

基于 `datetime` 格式化日期；在中文环境下自动把 strftime 输出的英文星期与月份翻译为中文。

**签名**：
- `格式化日期(时间=空, 格式="%Y-%m-%d", 语言=空) -> 文本`
- `星期名称(时间=空, 语言=空) -> 文本`
- `月份名称(时间=空, 语言=空) -> 文本`

**参数**：`时间` 可为日期、时间戳、ISO 时间文本或空（取当前时间）。

**示例**：
```
打印(格式化日期("2026-11-27", "%Y年%B%A", "zh")) // 2026年十一月星期五
```

**异常**：`类型错误`：参数类型不正确；`运行时错误`：时间戳或时间文本无效
