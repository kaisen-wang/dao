# 高阶内置函数

## 函数

| 函数名 | 参数个数 | 描述 |
| --- | --- | --- |
| 映射 | 2 | 映射：对每个元素应用函数，返回新列表 |
| 筛选 | 2 | 筛选：保留满足条件的元素 |
| 折叠 | 3 | 折叠：从初始值开始，逐个合并元素 |
| 每个满足 | 2 | 每个满足：所有元素是否都满足条件 |
| 存在满足 | 2 | 存在满足：是否有元素满足条件 |
| 查找 | 2 | 查找：找到第一个满足条件的元素 |
| 排序 | 可变参数 | 排序：对集合排序 |
| 展平映射 | 2 | 展平映射：映射后展平一层 |
| 分组 | 2 | 分组：按函数返回值分组 |
| 映射流 | 2 | 映射流：对流惰性映射，返回新流 |
| 筛选流 | 2 | 筛选流：对流惰性筛选，返回新流 |
| 取 | 2 | 取：从流中取前 n 个值，返回列表 |
| 柯里化 | 1 | 柯里化函数：将多参数函数转换为单参数函数链 |
| 组合 | 可变参数 | 函数组合：组合(f, g) 返回函数 f(g(x)) - 从右到左应用（传统数学定义） |
| 管道组合 | 可变参数 | 管道组合：管道组合(f, g, h) 等价于 x => h(g(f(x))) - 从左到右应用 |
