# 输入输出

## 打印

输出内容到控制台。

**签名**：`打印(*值, 分隔符: 文本 = " ", 结尾: 文本 = "\n")`

**参数**：
- `*值`：要输出的值，可传入多个
- `分隔符`：多个值之间的分隔符，默认为空格
- `结尾`：输出末尾的字符，默认为换行符

**返回**：`空`

**说明**：
- 布尔值 `真`/`假` 输出为中文
- `空` 值输出为"空"
- 对象实例输出其字符串表示

**示例**：
```
打印("你好，世界！")  // 你好，世界！
打印(1, 2, 3)  // 1 2 3
打印(1, 2, 3, 分隔符=", ")  // 1, 2, 3
打印("不换行", 结尾="")  // 输出后不换行
打印(真)  // 真
打印(假)  // 假
打印(空)  // 空
```

## 输入

从控制台读取用户输入。

**签名**：`输入(提示: 文本 = "")`

**参数**：
- `提示`：输入提示文本

**返回**：用户输入的字符串

**示例**：
```
定义 名字 = 输入("请输入你的名字：")
打印("你好，" + 名字)
```

## 读字节

从标准输入读取指定字节数，返回字节数据。

**签名**：`读字节(n: 整数) -> 字节`

**参数**：
- `n`：要读取的字节数，必须为正整数

**返回**：读取到的字节数据

**异常**：
- `类型错误`：`n` 不是整数
- `运行时错误`：`n` 不是正整数

**示例**：
```
定义 数据 = 读字节(4)  // 从标准输入读取 4 字节，返回字节数据
```

## 字节长度

返回文本的 UTF-8 编码字节数。

**签名**：`字节长度(文本: 文本) -> 整数`

**参数**：
- `文本`：要计算字节数的文本

**返回**：UTF-8 编码后的字节数（一个中文字符通常占 3 字节）

**异常**：`类型错误`：参数不是文本

**示例**：
```
打印(字节长度("你好"))  // 6
打印(字节长度("abc"))  // 3
```

## 错误输出

输出内容到标准错误流，语义与 `打印` 一致。

**签名**：`错误输出(*值, 分隔符: 文本 = " ", 结尾: 文本 = "\n", 刷新: 布尔 = 假)`

**参数**：
- `*值`：要输出的值，可传入多个
- `分隔符`：多个值之间的分隔符，默认为空格
- `结尾`：输出末尾的字符，默认为换行符
- `刷新`：为真时立即刷新标准错误缓冲区

**返回**：`空`

**说明**：值的中文转换规则与 `打印` 完全相同（`真`/`假`/`空` 输出为中文）

**示例**：
```
错误输出("出错了")  // 写入标准错误流
错误输出("错误", 42, 分隔符="-")
错误输出("不换行", 结尾="")
```

## 诊断源码

对源码字符串做词法与语法分析，返回诊断列表。

**签名**：`诊断源码(源码字符串: 文本) -> 列表`

**参数**：
- `源码字符串`：待分析的道语言源码

**返回**：诊断字典列表，每项包含中文键 `行`（1 起始）、`列`（1 起始）、`类型`（`词法错误` 或 `语法错误`）、`消息`（中文描述）；源码正确时返回空列表

**异常**：`类型错误`：参数不是文本

**示例**：
```
打印(诊断源码("定义 x = 1"))  // []
定义 诊断 = 诊断源码("定义 x = ")
打印(诊断)  // [{"行": 1, "列": 8, "类型": "语法错误", "消息": "..."}]
```
