# 示例清单

本目录包含 8 个循序渐进的 `.道` 示例，全部为单文件、无交互输入，可直接运行。

## 运行方式

在仓库的 `源码` 目录下，用隔离解释器执行：

```bash
cd /home/carson/code/test/道/源码
./.venv/bin/python main.py ../教程/示例/文件名.道
```

例如：

```bash
./.venv/bin/python main.py ../教程/示例/01_你好世界.道
```

> 说明：模块搜索基于当前工作目录（`os.getcwd()`）。若以后加入跨文件导入的示例，请先 `cd` 到本目录再运行。

## 清单

| 文件 | 覆盖知识点 |
|------|-----------|
| [01_你好世界.道](01_你好世界.道) | 打印、模板字符串、字符串插值、中文标点 |
| [02_变量与运算.道](02_变量与运算.道) | 定义/常量、数值/文本/布尔、算术与逻辑运算 |

| [05_面向对象.道](05_面向对象.道) | 类型/初始化/本对象、继承/父对象、特征、多态 |
