# 道语言 · 10 分钟入门

「道」是一门用中文关键字编写的、支持多种编程范式（命令式、函数式、面向对象、逻辑推理、并发）的解释型语言。本教程用 8 个可实际运行的示例，带你从环境准备一路走到一个跨范式的小项目。

全部内容均为中文，示例位于 `教程/示例/`。每个示例都可以直接运行，不依赖 `输入()`，适合自动化验证。

## 0. 环境准备

- Python **3.10 及以上**（项目仓库自带隔离解释器符号链接 `源码/.venv`）。
- 无需额外安装包；用隔离解释器直接运行主入口 `源码/main.py` 即可。

进入源码目录，运行任意 `.道` 文件：

```bash
cd /home/carson/code/test/道/源码
./.venv/bin/python main.py 文件.道
```

不带参数运行 `./.venv/bin/python main.py` 会进入交互式命令行（REPL）。

> 注意：模块搜索基于当前工作目录（`os.getcwd()`）。如果示例涉及跨文件导入，请先 `cd` 到示例所在目录再运行。本教程的 8 个示例均为单文件，无需切换目录。

## 1. 第一个程序

示例：[01_你好世界.道](示例/01_你好世界.道)

```dao
打印("你好，世界！")
打印("欢迎来到道语言！")

定义 名字 = "小明"
定义 年龄 = 12
打印(`你好，我是{名字}，今年{年龄}岁。`)
打印(`明年我就{年龄 + 1}岁了！`)

打印（“中文括号也能正常打印”)
```

要点：

- 用 `打印(...)` 输出，中文括号 `（）` 和西文括号 `()` 都可以。
- 反引号 `` ` `` 包围的是**模板字符串**，`{...}` 里可以写表达式，例如 `{年龄 + 1}`。
- 中文标点（如 `，`、`！`）可以正常出现在字符串里。

实测输出：

```
你好，世界！
欢迎来到道语言！
你好，我是小明，今年12岁。
明年我就13岁了！
中文括号也能正常打印
```

## 2. 变量、常量与运算

示例：[02_变量与运算.道](示例/02_变量与运算.道)

要点：

- `定义` 声明变量，`常量` 声明不可重新赋值的量。
- 基础类型：数值、文本、布尔（`真`/`假`）、空值（`空`）、列表、字典等。
- 算术运算符：`+ - * / // % **`；比较运算符支持链式写法 `1 < 分数 <= 100`。
- 逻辑运算符用中文：`并且`、`或者`、`不是`。
- `文本(...)` 把任意值转成可打印文本。

实测输出（节选）：

```
姓名：张三，年龄：25，已成年：真，为空：空
圆周率：3.14159
10 + 3 = 13
10 // 3 = 3
2 ** 10 = 1024
分数 85 在 1 到 100 之间
成年且通过
列表：[1, '苹果', True]
字典：{'姓名': '李四', '年龄': 30}
```

## 3. 条件与循环

示例：[03_控制流.道](示例/03_控制流.道)

要点：

- 分支：`如果` / `否则如果` / `否则`，靠缩进表示代码块。
- `当` 实现条件循环；`遍历 每个 在 列表` 遍历集合；`遍历 n 从 1 到 5` 遍历范围（含终点），可加 `步长 2`。
- `遍历 科目, 分 在 字典` 遍历键值对。
- `继续` 跳过本轮，`跳出` 提前结束循环。

## 4. 函数、递归、闭包与管道

示例：[04_函数与闭包.道](示例/04_函数与闭包.道)

要点：

- `函数 名称(参数)` 定义函数，`返回` 返回结果（`返回` 是关键字，不能当变量名）。
- 匿名函数：`函数(x) => x * x`。
- 递归：函数体内调用自身，例如阶乘。
- 闭包：外层函数返回内层匿名函数，内层记住外层变量。
- 高阶函数：`映射`、`筛选`、`折叠`；管道 `|>` 把左侧结果传给右侧函数继续处理。

实测输出：

```
加法(3, 4) = 7
平方(5) = 25
5! = 120
加十(5) = 15
平方列表：[1, 4, 9, 16, 25]
偶数列表：[2, 4]
总和：15
管道结果：[4, 16]
```

## 5. 面向对象

示例：[05_面向对象.道](示例/05_面向对象.道)

要点：

- 用 `类型` 定义类，`初始化(...)` 是构造函数，`本对象` 相当于 `this/self`。
- 继承用 `类型 子类 继承自 父类`，父类方法通过 `父对象.初始化(...)` 调用。
- `特征` 定义行为契约（可带默认实现）；类型在类体内第一行用 `实现 特征名` 接入。
- 同名方法在不同类型上表现出不同行为，即多态。

实测输出：

```
我是咪咪，今年3岁
喵，我是咪咪
喵~
白色的咪咪
咪咪 说：喵~
花花 说：喵~
小猫是猫？真
小猫是动物？真
```

## 6. 逻辑推理

示例：[06_逻辑推理.道](示例/06_逻辑推理.道)

要点：

- `逻辑 名称` 定义知识块，`事实: 谓词(...)` 写事实，`规则: 谓词(...) 如果 ...` 写规则。
- 逻辑变量以 `?` 开头，例如 `?孩子`。
- 用 `查询(知识块, 谓词(?变量))` 得到解的列表。
- 结果字典的键带 `?` 前缀，必须用 `解["?孩子"]` **下标访问**，不能用 `解.孩子`。
- 通过规则查询时，查询变量名建议与规则中的变量名保持一致，才能直接拿到具体值。

实测输出：

```
张三的孩子：小明
张三的孩子：小红
规则查到：小明
规则查到：小红
有权限：张三
```

## 7. 并发初探

示例：[07_并发初探.道](示例/07_并发初探.道)

要点：

- `并行` 启动协程；`通道(容量)` 创建带缓冲的通道，用 `.发送(值)` / `.接收()` 通信。
- `异步 函数` 定义异步函数，调用时用 `等待 函数(...)` 取得结果。
- 示例先用并行协程把结果写入缓冲通道，主线程再按固定次数接收，因此输出顺序稳定、便于验证。

实测输出：

```
通道收到：[10, 20, 30]
异步结果：42
```

## 8. 综合小项目：学生成绩分析

示例：[08_综合项目.道](示例/08_综合项目.道)

这个例子融合了三种范式：

- **面向对象**：`类型 学生` 封装姓名、分数和 `评价()` 方法。
- **函数式**：用管道 `|>` 串联 `筛选` 与 `映射`，并用标准库的 `平均值` 统计。
- **逻辑推理**：把优秀学生写成事实，用规则查询出可推荐的人。

同时演示了标准库导入的正确写法：`从 数学 导入 平均值`。

实测输出：

```
张三：95 分，优秀
李四：82 分，及格
王五：58 分，待提高
赵六：90 分，优秀
优秀学生：['张三', '赵六']
平均分：81.25
推荐：张三
推荐：赵六
```

## 避坑指南（实测结论）

1. **标准库只能用 `从 模块 导入 名称`。** `导入 模块` 会过滤掉 `BuiltinFunction`，例如 `导入 数学` 后再写 `数学.正弦(0)` 会报「对象没有属性 '正弦'」。官方文档里的 `导入 网络` 写法实际跑不通。
2. **`返回` 是关键字，不能当变量名。** 想表达返回值含义请换名字，例如 `结果`。
3. **`//` 行尾注释可用，但注意与整除的歧义。** `定义 x = 5 // 说明，这里是文字` 已能正确解析（右操作数为文字时按注释处理）；`10 // 3`、`被除数 // 除数` 仍按整除处理。若 `//` 后是紧跟变量的复杂表达式，建议加括号写成 `x // (y + 1)` 以彻底避免歧义。注释里的顿号 `、` 不再是问题。
4. **逻辑查询结果用下标访问。** 结果字典的键带 `?` 前缀，必须写 `解["?行动"]`，不能写 `解.行动`。
5. **断言时先算好布尔值。** `断言` 条件里直接写 `==` 在部分场景会被误判失败；稳妥做法是先赋值到布尔变量再断言：
   ```dao
   定义 相等 = x == 5
   断言 相等, "x 应等于 5"
   ```
6. **跨文件导入要先 `cd` 到示例目录。** 模块搜索基于 `os.getcwd()`，从别的目录运行会找不到模块。本教程示例均为单文件，不受影响。
7. **列表追加用 `.追加(元素)` 或 `追加(列表, 元素)`**，不是 `.添加(...)`。
