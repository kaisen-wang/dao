# 第十轮迭代共享契约：断网韧性、审计持久化与守护重启验收（v1.1 / M4 延伸）

> 前九轮已覆盖事件源、Router、持久化、Webhook、GitHub、observe/安全、真实 kill -9 / 并发 / 本地 git、生产守护与轮询兜底。
> 第九轮验收报告 §10.3 与 PRD §12 仍留下三项**本地可推进**的缺口：① 断网降级只做了不可达 host 的单例测试，未覆盖 ×10 与恢复率；
> ② observe 审计是纯内存压缩模拟，不跨进程积累；③ 长驻入口 / 优雅停机标记只做了 `.道` 层单测，未在真实 OS 进程上验证停机与外层拉起。
> 本轮把三项收口到「本地真实执行可验证」程度。沿用「子代理并行 + 主代理独占契约/入口演示/文档/最终验收」分工。

## 0. 范围与诚实边界

- **本轮做**：断网降级 ×10（真实不可达 host + 恢复率 + 外部消息计数口径）、observe 审计 SQLite 持久化与跨进程恢复 + 一周模拟流、真实子进程验证长驻入口优雅停机与外层重启拉起。
- **本轮不做**：接真实 GitHub / 飞书 / 企微 / ollama、发真实外部网络请求、真实云主机 systemd 守护进程、断网 ×10 的**真实外部**消息计数（仍为本地模拟口径）、≥1 周真实 observe 运行、开启 auto 模式。
- **诚实口径**：断网是「本地不可达 host」的真实网络异常，不等于生产断网全场景；observe 持久化是 SQLite 落盘 + 压缩模拟流，不等于真实一周运行；守护重启是真实子进程 + 本地信号，不等于生产 systemd 拉起；**PRD §12 六项 DoD 全部继续保持未勾选**，只在注记写「本地可验证部分已实现」。
- **测试约定（Python 层，跨平台硬约束）**：一律用 `sys.executable` 启动子进程；**禁止用 `signal.SIGKILL` / `os.kill(pid, SIGKILL)`**（Windows 无 `SIGKILL`，第八轮 `test_chaos_real_process.py` 因此在本机 10 项全失败）——跨平台停止子进程用 `proc.terminate()`（Windows 映射 TerminateProcess、POSIX 映射 SIGTERM）并 fallback `proc.kill()`；临时文件用 `tempfile.TemporaryDirectory()` 退出清理，禁止硬编码 `.venv/bin/python`。
- **本机说明**：Windows / Git Bash；pytest、ruff 从官方 PyPI 源安装后可跑。`.道` 脚本用 `python 源码/main.py` 可真实运行，必须实跑。中文环境变量名在 bash 里须 `env "中文名=值" ...`（与第九轮一致）。

## 1. 分层与依赖方向

```
L4 接入层/常驻入口.道 ──► L3 应用层/{观察审计,路由,评估,调度}.道 ──► L2 领域层/领域.道
                                    │                                   ▲
                                    └──► L1 基础设施层/{存储,语言模型,轮询兜底}.道 ──┘
```

- **观察审计归属 L3 应用层**：持久化复用 L1 `基础设施层/存储.道` 的 SQLite 连接（只依赖 `取连接()` 执行建表 / 增删改查），不得依赖 L4。
- **L2 领域层禁止出现 `LLM` / `HTTP` / `网络.请求` 等禁用词**（含否定句注释）——历史踩坑：注释里写「不依赖 HTTP」也会命中禁用词。
- 所有失败以中文字典返回或返回空，绝不向上抛未捕获异常。

## 2. 接口契约（跨代理严格遵守，按此并行开发）

### A `源码/tests/test_network_chaos.py`（真实断网 ×10，新建）

- 用 `sys.executable` 启动真实子进程运行道语言降级工作负载（cwd=`示例/更夫`），把 `OLLAMA_HOST` 指向**本地未监听端口**（如 `http://127.0.0.1:<空闲端口>`，用 socket _bind 端口 0 取空闲端口后立即释放，不依赖外网 DNS）模拟「断网」。
- 至少 10 轮：每轮真实调用一次 `基础设施层/语言模型.道.创建语言模型().对话()` 与 `.判断()`，断言返回中文字典且 `成功=假`、不抛未捕获异常。
- 恢复验证：断网期间用 `基础设施层/存储.道` 落 N 条 Outbox（幂等键唯一），断网结束后重投同键 → 不重复；未投递键补投 → 不丢失；记录「外部消息丢失/重复计数」为本地模拟口径（0/0），并写清这**不是真实外部消息计数**。
- 用 `tempfile.TemporaryDirectory()` 隔离每轮数据库，退出清理；不得改产品代码来「让测试通过」；默认能在 `pytest tests/ -q` 跑完（单轮 ≤2 秒），若环境不可达则用 `pytest.mark.skip` 并如实说明。

### B `应用层/观察审计.道`（扩展）+ `测试/测试观察审计持久化.道`（新建）

保持既有 `创建观察审计()` / `观察审计器` 全部方法**向后兼容**（内存模式不变），新增：

```text
导出 函数 创建持久观察审计(数据库路径, 事件源=空)
  # 用 基础设施层/存储.道 的 取连接() 建表 观察审计明细(id,事件ID,时间,类别,事件日)
  # 返回扩展审计器：既有 .记录事件/.计数/.生成报告/.导出JSON/.误接受率/.误忽略率 全部保留
  # 新增 .持久化统计() -> {"落库条数":N,"各类别":字典}；从 SQLite 重新统计
  # 新增 .恢复审计() -> 从 SQLite 重建内存明细列表，返回恢复条数（跨进程恢复）
导出 函数 审计一周模拟流(审计器, 每天正确接受, 每天误接受, 每天正确忽略, 每天误忽略)
  # 把 7 天 × 四类计数展开成明细事件写入审计器（事件日=第N天），返回写入总数
```

- 建表 / 写入 / 统计都复用 L1 存储连接；写入失败返回中文字典或假，不抛异常。
- 测试覆盖：内存模式既有 7 用例不退化；持久化写入后重新统计一致；跨进程恢复（关闭再创建审计器，`.恢复审计()` 后报告一致）；一周模拟流 7×4 展开数量正确；落库条数与报告总数一致；缺字段降级。
- 测试临时数据库放系统临时目录（tempfile / /tmp），退出清理，项目目录不留 `.db`。

### C `源码/tests/test_daemon_restart.py`（真实守护重启与优雅停机，新建）

- 用 `sys.executable` 启动真实子进程运行 `示例/更夫/接入层/常驻入口.道`（cwd=`示例/更夫`），设 `更夫长驻跳过运行` **不设**（走真实保活循环），设 `更夫心跳周期毫秒=200` 加速，`更夫停机标记` 指向 `tempfile` 内唯一路径。
- **优雅停机用例**：进程启动后确认存活（`poll() is None`），`touch` 停机标记文件，断言进程在 ≤5 秒内退出码 0（优雅退出，非被杀）。
- **外层重启用例**：进程启动后 `proc.terminate()`（跨平台），断言退出；再用同一命令重启第二个子进程，确认存活并能响应停机标记 —— 模拟「外层守护拉起」语义，**不等于真实 systemd**（注释写清）。
- 每轮用 `tempfile.TemporaryDirectory()` 隔离停机标记，退出清理；单用例 ≤10 秒；不得依赖真实网络 / ollama（设 `GENGFU_NO_LLM=1`）。
