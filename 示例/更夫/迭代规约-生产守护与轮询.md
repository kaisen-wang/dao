# 第九轮迭代共享契约：生产守护收口与定时轮询兜底落地（v1.1 / M4 延伸）

> 前八轮的能力已覆盖事件源、Router、持久化、Webhook、observe/安全，并用真实 OS 进程 / 并发 / 本地 git 逼近验收。
> 第八轮验收报告 §9.3 与文档 18 §18.16.3 明确留下四个**本地可实现**的缺口：① systemd 中文单元名被拒需 ASCII 改名；
> ② 中文环境变量名被拒需包装脚本 export；③ `接入层/入口.道` 跑完即退，配合 `Restart=always` 会循环拉起，缺一个真正的长驻入口；
> ④ 定时轮询兜底只有方案说明、未写代码。本轮把这四项收口到「可本地验证」的程度。
> 沿用「子代理并行 + 主代理独占契约/入口演示/文档/最终验收」分工。

## 0. 范围与诚实边界

- **本轮做**：ASCII systemd 单元名 + 环境变量包装脚本；supervisor 对齐长驻入口；独立长驻入口（主线程保活 + 优雅停机标记）；
  定时轮询兜底组件（事件源注入 + 幂等去重 + 复用 webhook 桥接回调）+ 定时启动封装；对应 `.道` 测试脚本；入口新增流程九演示。
- **本轮不做**：接真实 GitHub / 飞书 / 企微、发真实网络请求、真实云主机部署验证、真实 systemd 守护进程拉起、
  断网 ×10、真实外部消息 0 丢失 0 重复计数、≥1 周 observe 运行、开启 auto 模式。
- **诚实口径**：本轮所有事件源均为**本地注入的模拟源**；「轮询兜底代码已实现」≠「真实平台补漏已验证」；
  「长驻入口可保活」≠「已在生产 systemd 下长稳运行」；**PRD §12 六项 DoD 全部继续保持未勾选**，只在注记里写「本地可验证部分已实现」。
- **测试约定（Python 层）**：一律用 `sys.executable` 启动子进程，临时文件用 `tempfile` 并退出清理，禁止硬编码 `.venv/bin/python`。
- **本机说明**：当前开发机为 Windows，无 `systemd-analyze`、无可用 pytest/ruff 安装源；unit/supervisor 语法改用 Python `configparser` + 文本断言静态校验，
  全量 pytest 与 ruff 在本机不可复现时须**如实记录为未跑**，不得伪造数字。`.道` 脚本用 `python 源码/main.py` 可真实运行，必须实跑。

## 1. 分层与依赖方向

```
L4 接入层/常驻入口.道 ──► L3 应用层/{路由,评估,调度}.道 ──► L2 领域层/领域.道
        │                          ▲
        └──► L1 基础设施层/{轮询兜底,GitHub事件,webhook接入,存储}.道 ──┘
```

- **轮询兜底归属 L1 基础设施层**：只做「事件源拉取 + 幂等去重 + 回调派发」，`回调` 由参数注入，**禁止 import L4 的 webhook服务**，
  避免 L1 反向依赖 L4；去重键口径与第七轮 webhook 重放防护一致（SHA256）。
- **L2 禁止出现 `LLM` / `HTTP` / `网络.请求` 等禁用词**（含否定句注释）——历史踩坑：注释里写「不依赖 HTTP」也会命中禁用词。
- 所有失败以中文字典返回或返回空，绝不向上抛未捕获异常。

## 2. 接口契约（跨代理严格遵守，按此并行开发）

### A `部署/` 目录（生产守护三件套）

1. `部署/systemd/gengfu.service`（**新建 ASCII 文件名**）
   - `[Unit]` 描述中文 OK，但**单元文件名与所有变量名必须 ASCII**；`After/Wants=network-online.target`。
   - `[Service]`：`Type=simple`；`ExecStart` 指向包装脚本 `部署/systemd/启动包装.sh`（绝对路径占位 `/opt/gengfu/...`，并在注释写明现场替换）；
     `ExecStop` 用 `/bin/sh -c 'touch /opt/gengfu/run/gengfu.stop'` 触发优雅停机；`WorkingDirectory` 指向 `示例/更夫`（注明模块搜索基于 cwd）；
     `Restart=always` + `RestartSec=5`；`User=gengfu`（生产专用账号）；日志交 journald，`SyslogIdentifier=gengfu`。
   - **不得**在 unit 内写任何中文环境变量名（systemd 259 会忽略）；改用 `EnvironmentFile=` 指向 ASCII 名的 env 文件或全部由包装脚本 export。
2. `部署/systemd/启动包装.sh`（**新建**）
   - `#!/bin/sh`，`export` 五个中文变量（`GENGFU_NO_LLM` / `更夫端口` / `更夫数据库` / `更夫Webhook端口` / `更夫演示模式`）为 ASCII 中转：
     先把值写在 ASCII 变量（`GENGFU_PORT` 等），再 `export 更夫端口="$GENGFU_PORT"` —— 使中文变量**真正进入进程环境**。
   - `cd` 到 `示例/更夫` 后 `exec <python> <main.py> 接入层/常驻入口.道`；路径用变量 + 绝对占位，注释写明现场替换。
   - 给出 `chmod +x` 说明；脚本本身要能通过 `sh -n` 语法检查。
3. `部署/supervisor/gengfu.conf`（新建或由 `更夫.conf` 改名对齐）
   - program 名用 ASCII `gengfu`；`command` 指向同一个包装脚本；`directory` 指向 `示例/更夫`；
     `autostart/autorestart=true`、`startsecs=5`、`stopwaitsecs` 覆盖心跳周期；日志按 50MB 轮转 5 份；
     `environment=` 可直接给中文变量（supervisor 不受 systemd 限制），与包装脚本口径一致。
4. `部署/README.md`：更新为第九轮——ASCII 单元名、包装脚本原理、长驻入口替代演示入口、优雅停机标记、
   轮询兜底启用方式、环境变量表、诚实边界（未做真实云主机部署 / 未接真实平台 / DoD 不勾选）。

### B `基础设施层/轮询兜底.道`（新建，L1）+ `测试/测试轮询兜底.道`（新建）

```text
导出 函数 轮询去重键(事件字典)              # SHA256(外部编号 + "|" + 事件类型)，稳定字符串；缺字段降级为空串拼接
导出 类型 轮询兜底器
    初始化(事件源, 回调, 已见集合=空)
      # 事件源: 无参函数，返回事件字典列表（本地注入模拟源；真实客户端后续补齐）
      # 回调:   单参函数(事件字典)，复用 webhook服务.创建Webhook桥接 产出的回调
      # 已见集合: 外部传入的 list/dict，跨调用共享去重；空则内部创建
    函数 轮询一次()   # 返回 {"成功":真,"拉取":N,"新事件":M,"重复跳过":K,"失败":J,"拉取失败":布尔}
    函数 已见数()     # 返回已见去重键数量
导出 函数 创建轮询兜底(事件源, 回调, 已见集合=空)  # 工厂，返回 轮询兜底器
导出 函数 创建定时轮询(轮询器, 间隔毫秒=60000, 调度注入=空)
      # 用 调度.周期执行 启动；返回 {"调度器":对象/空,"调度ID":整数/空,"轮询器":轮询器}
      # 调度注入 便于测试传入假调度器（.周期执行 返回整数、.取消调度 记录调用）；为空时从 调度 导入真实原语
```

- 事件字典约定键：`外部编号` / `事件类型`（兼容 webhook 归一化结果的 `消息ID` / `事件类型` / `话题键`）。
- 去重：同一 `轮询去重键` 已出现则跳过、不调回调；新键追加到已见集合并调回调；回调抛异常记入 `失败`、不中断其余事件。
- 事件源抛异常 → 返回 `拉取失败=真`、`拉取=0`，不向上传播。
- 测试至少覆盖：新事件全派发、重复事件仅派发一次、回调异常隔离、事件源异常降级、去重键稳定性、定时封装用假调度器记录周期调用。

### C `接入层/常驻入口.道`（新建，L4）+ `测试/测试长驻入口.道`（新建）

```text
// 长驻入口：主线程保活 + 优雅停机，配合 systemd/supervisor 的 Restart=always 不循环拉起。
// 运行：cd 示例/更夫 && python ../../源码/main.py 接入层/常驻入口.道
// 停机：touch <更夫停机标记> 环境变量指定的文件（默认 /tmp/gengfu.stop），心跳检测到则取消全部调度并退出循环。
```

- 启动打印横幅（长驻入口标识、端口、停机标记路径、轮询周期）；用 `调度.周期执行` 注册心跳（复用 `守护.道` 的统计口径，5 秒）与可选定时轮询。
- **可测试性**：与 `webhook服务.道` 一致，设置环境变量 `更夫长驻跳过运行=1` 时只执行初始化与横幅、进入有限次循环后退出，供 `.道` 测试断言导出函数与初始化，不阻塞。
- **优雅停机**：把「是否停机 + 单次心跳」逻辑抽成导出函数 `导出 函数 长驻心跳(停机标记路径, 轮询器=空)`，返回 `{"继续":布尔,"已停机":布尔}`；
  测试直接调该函数注入停机标记文件断言返回，不必真的长跑。
- 测试至少覆盖：导出函数存在且可调用、未放标记时 `继续=真`、放标记后 `已停机=真` 且 `继续=假`、标记路径缺省行为。
