# 第十一轮迭代共享契约：真跨进程恢复、Watchdog 时间化与真子进程规则执行（v1.1 / M4 延伸）

> 前九轮已覆盖事件源、Router、持久化、Webhook、GitHub、observe/安全、真实 kill -9 / 并发 / 本地 git、生产守护与轮询兜底；第十轮收口断网 ×10、observe 落盘、守护重启。
> 第十轮验收注记（PRD §12 / 文档 18 §18.18.3 / 验收报告 §11.3）留下三项**诚实缺口**：
> ① observe「跨进程恢复」是同进程内「关闭后新建审计器」模拟，非两个独立 OS 进程；
> ② FR-16 Watchdog 只是 L4 `入口.道.巡检停滞()` 的无时间阈值计数桩，无 nudge / 告警决策、无「30 分钟内发现」验收；
> ③ 并发压测 `test_load_real_concurrency.py` 的判定链是 Python 等价复刻，非真实 `.道` 规则链在子进程中执行。
> 本轮把三项推进到「本机真实 OS 进程可验证」程度。沿用「子代理并行 + 主代理独占契约/入口演示/文档/最终验收」分工。

## 0. 范围与诚实边界

- **本轮做**：两个独立 OS 进程验证 observe 审计 SQLite 跨进程恢复一致性；L3 Watchdog 模块（时间阈值 + nudge/告警 + 注入停滞任务发现）；真实 OS 子进程跑 `.道` 准入/评估规则链的并发压测。
- **本轮不做**：接真实 GitHub / 飞书 / 企微 / 真实 ollama、发真实外部网络请求、真实云主机 systemd、真实 ≥1 周 observe、开启 auto 模式、改 L2 `领域.道` 与 L1 `存储.道`。
- **诚实口径**：跨进程恢复是真 OS 进程但仍是本地 SQLite；Watchdog 的时间阈值用注入的历史时间戳模拟「停滞 30 分钟」，不是真等 30 分钟；规则链是真 `.道` 解释器子进程，但事件仍是本地构造、非真实 webhook。**PRD §12 六项 DoD 全部继续保持未勾选**，只在注记写「本地可验证部分已实现」。
- **测试约定（Python 层，跨平台硬约束）**：一律用 `sys.executable` 启动子进程；**禁止 `signal.SIGKILL` / `os.kill(pid, SIGKILL)`**；停止子进程用 `proc.terminate()` 并 fallback `proc.kill()`；临时文件用 `tempfile.TemporaryDirectory()` 退出清理；禁止硬编码 `.venv/bin/python`；`.道` 子进程 cwd 必须是 `示例/更夫`（模块搜索基于 `os.getcwd()`）。
- **本机说明**：Linux x86-64 / Python 3.13.12（`/home/carson/.workbuddy/binaries/python/envs/default` 的 `.venv` 软链）；全量基线 `1661 passed / 2 skipped / 1 xpassed`（本轮零基线回归）。`.道` 脚本实跑命令：`cd 示例/更夫 && GENGFU_NO_LLM=1 python ../../源码/main.py <脚本>`。

## 2. 接口契约（跨代理严格遵守，按此并行开发）

### A `crossproc-audit`：`源码/tests/test_observe_cross_process.py`（新建）

- 用 `sys.executable` 启动**两个独立 OS 子进程**运行 `.道` 工作负载（cwd=`示例/更夫`，`.道` 脚本由测试在 `tempfile.TemporaryDirectory()` 内生成，用 ASCII 环境变量传路径）：
  - **Writer 进程**：`从 应用层.观察审计 导入 创建持久观察审计, 审计一周模拟流`；`创建持久观察审计(库路径)` → `审计一周模拟流(审计器, ...)` 写入 7 天 × 四类明细 → 打印落库总数后**正常退出**（进程真实结束）。
  - **Reader 进程**（writer 退出后另起）：同样打开该库 → `.恢复审计()` → `.生成报告()` + `.持久化统计()` → 打印 JSON 报告后退出。
- 测试解析两个进程的 stdout，断言：reader 恢复条数 == writer 写入数；reader 报告总数/四类计数/误接受率与 writer 一致；`.持久化统计()` 的落库条数一致；读库不修改 writer 数据（重复 reader 结果相同）。
- 另加一个「空库 reader」用例：新临时库中恢复返回 0、报告总数 0、不抛异常。
- 至少 5 个用例；单用例 ≤5 秒；`GENGFU_NO_LLM=1` 注入子进程环境；注释写清「真 OS 进程 + 本地 SQLite ≠ 真实一周 observe」。
- 不得修改产品代码（尤其 `应用层/观察审计.道`、`基础设施层/存储.道`）；测试临时目录退出清理，项目目录不留 `.db`。

### B `watchdog`：`应用层/巡检.道`（新建）+ `测试/测试看门狗.道`（新建）

保持 L4 `入口.道.巡检停滞()` 原样（主代理独占，不改）；新模块作为 FR-16 的真实现：

```text
从 领域层.领域 导入 阶段执行中, 阶段结束, 报告受阻, 报告失败, 建报告

导出 函数 创建看门狗(停滞阈值分钟=30, 告警阈值分钟=60)
  # 返回 看门狗对象，字段：停滞阈值分钟/告警阈值分钟/最近巡检明细=[]/巡检次数=0

类型 看门狗
    函数 巡检(工单列表, 报告映射=空, 当前时间=空)
      # 当前时间为空时用 时间戳()（单位：秒）；允许注入整数便于测试。
      # 判定「停滞」：工单.阶段 == 阶段执行中 且 (工单.绑定==空 或 工单.绑定.状态!="running")
      #              且 (当前时间 - 工单.创建时间) >= 停滞阈值分钟*60
      # 判定「告警」：停滞时长 >= 告警阈值分钟*60；否则为 nudge（提醒）。
      # 报告映射形如 {"工单编号":[报告,...]}；含 报告受阻/报告失败 的工单升级为告警。
      # 每次调用 巡检次数+1；最近巡检明细覆盖为 [{"工单编号","停滞分钟","级别","建议"}]
      # 级别取 "正常"/"nudge"/"告警"；建议为中文短句。
      # 返回中文字典 {"巡检次数":N,"停滞数":N,"nudge数":N,"告警数":N,"明细":列表,"说明":中文边界说明}
    函数 注入停滞任务(工单编号, 标题, 停滞分钟, 当前时间=空)
      # 构造并返回 L2 工单对象：阶段=阶段执行中、绑定=空、创建时间=当前时间-停滞分钟*60。
      # 供「注入停滞任务 30 分钟内被发现」验收：29 分钟不算停滞、31 分钟算 nudge、61 分钟算告警。
    函数 生成nudge决策(工单编号, 停滞分钟)
      # 返回 L2 决策(工单编号, "nudge", 中文理由, 策略版本="v0.1")
    函数 生成告警决策(工单编号, 停滞分钟)
      # 返回 L2 决策(工单编号, "alert", 中文理由, 策略版本="v0.1")
```

- `测试/测试看门狗.道`（`从 系统 导入 退出`，失败计数 + 退出码）覆盖至少 9 项：创建默认值；29 分钟不发现；31 分钟发现且级别 nudge；61 分钟告警；受阻报告升级告警；结束态工单不报停滞；nudge/告警决策结论与中文字段；多次巡检计数与明细覆盖；注入固定当前时间避免依赖真实等待。
- 注释写清「注入历史时间戳模拟 30 分钟，不是真等 30 分钟；FR-16 真实定时巡检仍需生产长驻环境」。

### C `rule-subprocess`：`源码/tests/test_rule_engine_real_process.py`（新建）

- 用 `sys.executable` 启动**真实 OS 子进程**运行测试在 `tempfile` 内生成的 `.道` 工作负载（cwd=`示例/更夫`，`GENGFU_NO_LLM=1`），工作负载必须 `从 应用层.准入 导入 判定` 与 `从 应用层.评估 导入 评估`（按实际导出名，先读源码确认），真实执行 `.道` 规则链而非 Python 复刻：
  - 工作负载从 ASCII 环境变量读取一批消息（用 JSON 文件或命令行参数传入），逐条调用真实 `.道` `判定()` / `评估()`，把结论（explicit/candidate/ignore/bot 与是否接受）写成 JSON 结果文件。
  - Python 侧用 `ThreadPoolExecutor` 并发启动多个子进程（每进程一批消息），对照口径沿用 `测试/压测.道`：280 噪音 + 20 显式 ×5 轮。
  - 硬指标：噪音误建单 = 0（判定结论为 explicit 的噪音数 0）；20 条显式全部判为 explicit；重复投递同一去重键只产生 1 条 Trigger（复用 `保存触发` 幂等）。
  - 记录 p50/p95/max 耗时，仅观测、不硬断言 p95 ≤ 基线 60%，如实写「本机真子进程并发 ≠ 生产真实流量」。
- 至少 5 个用例；单用例 ≤10 秒；跨平台停止子进程用 `proc.terminate()`；注释写清「判定链由真 `.道` 解释器子进程执行，弥补第八轮『Python 等价复刻』缺口；事件仍为本地构造」。
- 不得修改产品代码；不得改 `test_load_real_concurrency.py`（保留其 Python 复刻路径作对照）。
