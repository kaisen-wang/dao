# 第五轮迭代共享契约：常驻 Router 会话与 IM 第二信道（v1.1 / M4）

> 对应 PRD《常驻研发协作 Agent》FR-17 / FR-18、§11 发布计划 v1.1（M4）。
> 沿用四子代理并行 + 主代理独占共享契约/领域层/入口/最终验收的分工。

## 0. 范围与边界

- **本轮目标**：把 v1.0 的「无状态 Eval」升级为有状态常驻 Router——会话保持、批处理、全局记忆、统一对外回复、链式召回工具；并补 IM 第二信道事件源适配器。
- **非 GitHub**：不接 GitHub webhook / PR / 评论投递。IM 适配器采用与 LLM Provider 相同的策略——**飞书/企微函数签名完备、可对接 HTTP，但默认走本地模拟**，不做真实外部请求。
- **LLM 仍是增强项**：测试与演示不依赖真实 ollama；不传语言模型时走关键词规则，端到端可跑。
- **诚实口径**：本地模拟通过 ≠ 真实 IM/GitHub 闭环通过；文档与 PRD 注记必须区分。

## 4. 模块接口契约

### 4.1 `应用层/路由.道`（子代理 A）

```text
从 领域层.领域 导入 消息, 会话, 信道GitHub, 信道飞书, 信道企微, 角色用户, 角色助手
导出 函数 创建路由(会话集合=空, 语言模型=空)
```

`创建路由` 返回一个路由对象，方法：

- `.开通会话(会话编号, 来源信道, 话题键)` → 会话对象；同一编号重复开通返回既有会话（幂等）。
- `.收消息(会话编号, 文本, 来源信道=信道飞书, 来源用户="")` → 响应字典
  `{"成功": 真/假, "会话编号": ..., "回复": 文本, "工单编号": ..., "消息数": n}`。
  - 写入用户消息到会话；命中「建单意图」（文本含「请修复/请处理/崩溃/失败」等）时调用 `应用层/执行.道.执行工单` 或至少生成一条本地工单记录并返回 `工单编号`；
  - 未命中时仅记录消息，给出中文确认回复；
  - 不传语言模型或调用失败时静默降级（不抛异常），回复带「关键词规则」标记。
- `.批处理(消息列表, 会话编号, 来源信道=信道飞书)` → 列表，逐条调用 `.收消息()`，返回每个响应字典。
- `.统一回复(会话编号)` → 取该会话最近助手消息拼成一段中文文本；无会话返回中文提示。
- `.全局记忆(话题键)` → 返回该话题下所有会话的最近消息列表（跨会话记忆，FR-17）。
- `.会话数()` → 整数。

**不实现真实网络 IO**，不做 fork/线程；所有状态在内存集合里。

### 4.2 `应用层/召回.道`（子代理 B）

```text
从 领域层.领域 导入 召回片段, 话题
导出 函数 创建召回器(存储=空)
导出 函数 串联召回(片段列表, 最大跳数=3)
```

- `创建召回器(存储)` 返回对象，方法 `.按工单(工单编号)`、`.按话题(话题编号)`、`.按关键词(关键词列表)` → 均返回 `召回片段` 列表。
  - 存储为空时返回空列表，不抛异常；
  - 从 `基础设施层/存储.道` 的 `列出工单()/列出决策()/列出报告()` 取数，转成片段（来源类型分别 "工单"/"决策"/"报告"）；
  - 参数校验失败返回空列表（中文降级，不中断主流程）。
- `串联召回(片段列表, 最大跳数=3)` → 去重后的片段列表：以首片段为起点，按「来源编号相同 / 内容关键词重叠」建立关联，逐跳扩出相关片段，最多 `最大跳数` 跳；结果按相关度降序，已访问片段不重复。
- 纯函数与领域对象操作，**不得导入 LLM / 网络标准库**。

### 4.3 `基础设施层/即时通信.道`（子代理 C）

```text
从 领域层.领域 导入 触发, 信道飞书, 信道企微
导出 函数 创建飞书适配器(应用ID="", 应用密钥="", 本地模式=真)
导出 函数 创建企微适配器(企业ID="", 应用密钥="", 本地模式=真)
导出 函数 归一化事件(适配器, 事件字典)
```

两个适配器均为对象，方法：

- `.可用()` → 本地模式恒为 `真`；非本地模式仅当凭据齐全为真（不发真实请求）。
- `.解析消息(事件字典)` → 归一化字典 `{"成功": 真, "消息ID": ..., "来源信道": ..., "发送人": ..., "话题键": ..., "文本": ..., "是否@机器人": 真/假}`；缺字段时 `{"成功": 假, "错误": 中文提示}`，不抛异常。飞书事件体形如 `{"event": {"message": {"content": "..."}, "sender": {...}}, "header": {...}}`；企微形如 `{"FromUserName": ..., "Content": ..., "ChatId": ...}`，两者都要容错。
- `.生成触发(事件字典)` → 归一化成功且 `是否@机器人` 为真时返回 `触发` 对象（用 `领域层.触发` 构造函数，参数以现有签名为准），否则返回 `空`。
- `.回复消息(话题键, 文本)` → 本地模式返回 `{"成功": 真, "已回复": 文本, "本地模拟": 真}`；非本地模式也只返回待发送字典（不真正发 HTTP）。

`归一化事件(适配器, 事件字典)` 为语法糖，等价于 `.解析消息()`。

### 4.4 `测试/测试Router接入.道`（子代理 D）

用「测试」标准库函数式 API（见 `测试/测试LLM接入.道`）：

```text
从 测试 导入 测试套件, 断言等于, 断言为真, 断言为假, 断言包含, 测试报告
定义 套件 = 测试套件("...")
套件.start()
...
如果 套件.failed > 0 退出(1)
退出(0)
```

至少覆盖 12 个用例：会话开通幂等、消息追加与最近消息、建单意图命中、非建单仅记录、批处理、统一回复、跨会话全局记忆、召回器按工单/话题/关键词、串联召回去重与跳数、飞书事件归一化、企微事件归一化、适配器本地模式与降级。
**不要断言真实 HTTP / 真实 IM 投递**。

## 6. 编码约定（历史踩坑，务必遵守）

- `规则` 是关键字，不能作变量名 → 用 `规则列表`。
- `类型` 是关键字 → 访问诊断类字典键用 `字典["类型"]`。
- 断言参数顺序：`断言等于(期望, 实际)`。
- `尝试/捕获` 会吞掉断言失败 → 测试末尾必须保留 `如果 套件.failed > 0 退出(1)`。
- `//` 行尾注释后紧跟数字会被判整除 → 注释独占整行，或避免以数字开头。
- 中文路径导入按点分目录解析（`从 基础设施层.即时通信 导入 ...` → `基础设施层/即时通信.道`），运行前必须 `cd 示例/更夫`。
- 标准库函数只能用 `从 模块 导入 名称`，`导入 模块` 会过滤掉内置函数。
