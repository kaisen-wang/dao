# 第六轮迭代共享契约：v1.1 / M4 收口（会话持久化 + IM Webhook 接入）

> 对应 PRD《常驻研发协作 Agent》FR-17/FR-18 第五轮注记中明确标注的两个缺口：
> ① Router 会话为内存态、重启即丢；② IM 适配器只做归一化与本地回执，未接 webhook。
> 沿用「四子代理并行 + 主代理独占共享契约/领域层/入口/文档/最终验收」的分工。

## 0. 范围与诚实边界

- **本轮做**：道语言层实现会话持久化存储；提供可接入的飞书/企微 webhook HTTP 端点（含验签、事件归一化、触发生成）；Router 支持注入存储并可恢复会话；补回归测试与文档。
- **本轮不做**：连接真实飞书/企微服务器、发真实消息、接 GitHub webhook/PR、真实进程拉起。
- **诚实口径**：webhook 端点「可被真实平台回调」与「已在真实平台验证闭环」是两回事，文档必须写清未做真实平台验证。
- **LLM 仍是增强项**：全部测试与演示不依赖 ollama（`GENGFU_NO_LLM=1` 必须可跑）。

## 1. 分层与依赖方向

```
L4 入口.道 / webhook服务.道 ──► L3 应用层/{路由,召回}.道 ──► L2 领域层/领域.道
                                        ▲
L1 基础设施层/{会话存储,即时通信,webhook接入,存储,看板}.道 ─┘
```

严格自上而下；L1 可依赖 L2 的类型/常量，不得依赖 L3/L4；L2 仍禁止出现 `LLM`/`HTTP`/`网络.请求` 等禁用词（含否定句注释）。

## 2. 接口契约（跨代理必须严格遵守，按此并行开发）

### A `基础设施层/会话存储.道`（新建）

```text
从 基础设施层.存储 导入 取连接
从 领域层.领域 导入 会话, 消息

导出 函数 创建会话存储(路径="更夫.db")
  .保存会话(会话对象)            # 幂等 UPSERT
  .读取会话(会话编号)            # 返回 会话 对象；不存在返回 空
  .保存消息(会话编号, 消息对象)   # 追加一条消息
  .列出消息(会话编号)            # 返回 消息 列表（按时间升序）
  .列出会话编号()                # 返回字符串列表
  .删除会话(会话编号)            # 级联删除其消息
  .会话数()                      # 返回整数
```

存储使用 `取连接()` 返回的 DaoConnection（`.执行()` / `.查询()` / `.提交()`），表名 `会话`、`会话消息`，列用 TEXT/INTEGER。消息字段：`角色/内容/来源信道/工单编号/时间`。
**注意**：`取连接()` 是既有全局连接；若测试需要独立文件库，允许 `创建会话存储(路径)` 时新建连接（用 `从 数据库 导入 连接`）。

### C `应用层/路由.道`（修改，向后兼容）

```text
导出 函数 创建路由(会话集合=空, 语言模型=空, 会话存储=空)
  # 新增 .恢复会话(会话编号) -> 会话对象或空（从存储载入内存）
  # 开通会话/收消息/追加消息时：若 会话存储 非空则同步持久化
  # 不传 会话存储 时行为与第五轮完全一致
```

### B `基础设施层/webhook接入.道` + `webhook服务.道`（新建）

```text
从 基础设施层.即时通信 导入 创建飞书适配器, 创建企微适配器, 归一化事件
从 密码 导入 HMACSHA256, 验证HMAC, SHA256

导出 函数 创建Webhook接入(平台="feishu", 应用ID="", 应用密钥="", 本地模式=真, 回调=空)
  .验证签名(请求对象) -> 布尔        # 飞书: HMAC-SHA256(时间戳\n随机数\nbody\n)；企微: token 比对
  .解析事件(请求对象) -> 字典        # 归一化后的统一事件字典
  .处理(请求对象) -> 响应字典        # 验签失败 401；成功生成触发并调用回调，回执 {"状态码":200,"内容":...}
```

`webhook服务.道`（L4）：从 `网络` 导入 `创建服务器`，注册 `POST /webhook/feishu`、`POST /webhook/wecom`，端口取环境变量 `更夫Webhook端口`（默认 8766）。默认本地模式，不发起任何真实外部请求。

### D `测试/测试持久化与Webhook.道` + `使用说明.md` + `架构说明.md`
