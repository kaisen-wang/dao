# 网络模块完整 Web 示例

一个**只用标准库、无外部依赖**的服务端 + 客户端示例：服务端用 `从 网络 导入 创建服务器` 注册路由，客户端用 `从 网络 导入 请求` 发 HTTP 请求并做有限重试。

## 运行方式（两个终端）

终端一，先启动服务器（会阻塞监听，按 Ctrl+C 停止）：

```bash
cd 示例/Web应用
python ../../源码/main.py 服务器.道
```

看到 `Web 示例服务已启动：http://127.0.0.1:18081/` 后，终端二运行客户端：

```bash
cd 示例/Web应用
python ../../源码/main.py 客户端.道
```

默认端口固定为 **18081**。若要改端口：修改 `服务器.道` 与 `客户端.道` 首行注释指出的同一行（或用环境变量 `WEB示例端口` 同时传给两个进程），否则客户端会连不上。

## 端点表

| 方法 | 路径 | 说明 | 成功响应 |
|------|------|------|----------|
| GET | `/` | HTML 首页，`内容类型` 为 `text/html; charset=utf-8` | 200 |
| GET | `/api/健康` | 健康检查 | 200，`{"状态": "正常"}` |
| POST | `/api/订单` | JSON 请求体含 `商品`/`数量` 时创建订单 | 201，`{"商品":..., "数量":..., "状态": "已创建"}` |
| POST | `/api/订单` | 缺字段或非法 JSON | 400，`{"错误": "缺少商品或数量"}` / `{"错误": "请求体不是合法的JSON"}` |
| GET | `/api/用户/*` | 通配路由，回显（百分号解码后的）用户名 | 200，`{"用户": "张三"}` |
| 任意 | 未匹配路径 | 服务器默认 404 兜底 | 404，`未找到路由` |

所有路由处理器统一返回标准响应字典 `{"状态码": ..., "内容": ..., "内容类型": ...}`。

## 客户端预期输出

```text
健康接口：HTTP 200 / 状态=正常
订单创建：HTTP 201 / 商品=键盘 / 数量=2
请求校验：HTTP 400 / 错误=缺少商品或数量
```

输出为逐行固定文本，不含时间戳、随机订单号等不稳定内容，便于断言。

## 客户端重试策略

- 对**网络异常**与 **5xx** 响应做最多 3 次尝试，线性退避（第 n 次失败后睡眠 `0.05 * n` 秒，来自 `从 时间 导入 睡眠`）。`睡眠` 与全局内置函数重名，示例用 `从 时间 导入 睡眠 作为 休眠` 避免重复定义。
- 对 **4xx 不重试**，直接打印状态码。
- 中文路径先用 `URL编码` 转成百分号形式再请求（urllib 不接受原始非 ASCII 路径）；服务端会自动解码后匹配路由。

## 常见错误

1. **端口占用**：启动时报 `无法启动服务器: [Errno 98] Address already in use`，说明 18081 已被其他进程占用。先停掉占用者，或临时给两个进程设置同一个 `WEB示例端口`（如 `WEB示例端口=18082`）。测试遇到占用会换空闲端口。
2. **4xx 不抛异常**：`请求()` 对 4xx/5xx **返回响应对象**（`响应.状态码` 为 400/500），**不会**抛异常；重试判断必须检查 `响应.状态码`。只有 `流式请求()` 才对 4xx/5xx 抛异常。
3. **连不上服务器**：客户端输出 `请求失败（网络异常）`，通常是服务器未启动、端口不一致，或路径没做 URL 编码；先确认终端一有启动日志，再核对两端端口。
4. **中文路径 404**：直接把 `/api/健康` 这样的原始中文路径交给 `请求()` 会编码失败；用 `URL编码` 处理后再请求，完整路径示例为 `/api/%E5%81%A5%E5%BA%B7`。
5. **重复定义错误**：`从 时间 导入 睡眠` 会因同名内置函数报「变量 '睡眠' 已经被定义过了」，需用别名；`等待` 又是保留关键字，示例选用 `休眠`。

## 回归测试

```bash
cd 源码 && python -m pytest tests/test_examples_web.py -q
```

测试用 `sys.executable` 真实启动服务器子进程、轮询就绪、跑客户端并断言输出，结束会 `terminate()` + `wait()` 回收进程，端口冲突时自动换空闲端口。
