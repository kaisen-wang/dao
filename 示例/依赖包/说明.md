# 依赖包示例

演示「把项目打成依赖包 → 安装到另一个项目 → 以包名导入」的完整流程。

```
依赖包/
├── 数学库/            # 库项目，将被打成 .道包
│   ├── 道.配置
│   ├── 主程序.道
│   └── 工具/辅助.道
└── 应用/              # 消费方项目，声明对数学库的依赖
    ├── 道.配置
    └── 主程序.道
```

## 运行步骤

在仓库根目录执行（把 `源码/main.py` 换成已安装的 `dao` 命令亦可）：

```bash
# 1. 打包库项目 → 数学库/数学库-1.2.0.道包
python 源码/main.py pack 示例/依赖包/数学库

# 2. 安装到应用项目 → 应用/道包/数学库/
python 源码/main.py install 示例/依赖包/数学库/数学库-1.2.0.道包 -p 示例/依赖包/应用

# 3. 查看已安装依赖
python 源码/main.py packages 示例/依赖包/应用

# 4. 运行应用，输出 5 和 42
cd 示例/依赖包/应用 && python ../../../源码/main.py run
```

说明：

- 库项目的 `道.配置` 里写了 `道版本 >=1.2.0`，该约束会随 `.道包` 一起分发；安装时会与当前解释器版本校验，不满足则报错，可用 `--skip-version-check` 跳过。`dao packages` 会显示该要求。
- `应用/道包/` 是安装生成的目录，不需要手工创建或提交；同一版本重复安装是幂等的，换版本需加 `--force`。

## 打包成可运行应用

把应用连同已安装的依赖打成 `.道应用`，再直接运行（可脱离原项目目录）：

```bash
python 源码/main.py build 示例/依赖包/应用
python 源码/main.py run 示例/依赖包/应用/应用-1.0.0.道应用
```

同样输出 `5` 和 `42`；`dao run` 遇到 `.道应用` 参数会在临时目录解压运行并自动清理。
