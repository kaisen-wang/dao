# 道语言编辑器插件

本目录收录「道」语言的编辑器扩展，让 `.道` 文件在主流编辑器中获得语法高亮与语言服务（诊断、补全、悬停、跳转）。

语言服务由项目内置的 LSP 服务器提供（`源码/dao/lsp/`，零第三方依赖，JSON-RPC over stdio），插件本身只负责按 LSP 协议与它通信。因此两个插件共享同一套能力，行为一致。

## 插件一览

| 编辑器 | 目录 | 安装方式 |
|--------|------|----------|
| VS Code | [`vscode/`](vscode/) | 见该目录 README（`vscode:extension` 或打包 `.vsix`） |
| Neovim | [`neovim/`](neovim/) | 见该目录 README（加入 `runtimepath`） |

## 前置条件

两个插件都依赖项目隔离解释器中的 LSP 模块。首次使用前确认：

```bash
cd 源码
./.venv/bin/python -m dao.lsp   # 正常启动后等待 stdin 输入，Ctrl+C 退出
```

若该命令报缺依赖，先按项目根 `AGENTS.md` 的说明初始化隔离环境：

```bash
cd 源码
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

## 能力清单（两插件一致）

- 语法高亮：关键字、注释、字符串、模板字符串、数值、`?` 逻辑变量、`!` 宏调用、`|>` 管道
- 诊断：词法 / 语法错误（中文消息）
- 补全：关键字、内置函数、标准库模块名、文档内标识符
- 悬停：关键字 / 内置函数 / 标准库模块的中文说明
- 跳转：当前文档内的函数 / 类 / 变量定义
- 文档符号：基于 AST 的大纲视图
- `道.配置` 支持：字段名高亮与补全（`名称` / `版本` / `道版本` / `作者` / `描述` / `入口` / `依赖` / `开发依赖`）
- 打包命令：在编辑器中调用 `pack` / `install` / `build` / `run`（运行应用包，VS Code 命令面板、Neovim 用户命令）

详细的协议能力、限制与编辑器侧配置原理见项目文档 `文档/14-LSP语言服务器.md`。

## 关键字覆盖校验

两个语法文件的高亮关键字须与权威表 `源码/dao/tokens.py` 的 `KEYWORDS`（79 项）保持一致；运行 `python3 编辑器插件/校验关键字.py` 即可逐一检查并输出缺失清单与 `79/79` 结果（路径相对脚本自身推导，可从任意目录执行；有缺失时退出码为 1）。

## 常见问题

**Q：没有补码 / 诊断？** 先按上面前置条件确认 `python -m dao.lsp` 能启动；再检查插件配置里的 Python 解释器路径是否指向 `源码/.venv/bin/python`。插件路径均为相对定位，若移动了目录结构需相应调整。

**Q：中文显示为乱码？** LSP 帧头的 `Content-Length` 按 UTF-8 字节数计算，插件不参与编码转换；确保编辑器以 UTF-8 打开 `.道` 文件即可。
