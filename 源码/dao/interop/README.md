# Python 互操作桥（白名单制）

让"道"语言在**受控、可审计**的前提下复用 Python 生态。设计目标是"先安全、再方便"：
桥本身不提供任意代码执行能力，只暴露一份静态白名单。

## 三个内置函数

| 道语言函数 | 说明 | 参数 |
| --- | --- | --- |
| `列出Python模块()` | 列出所有可加载的模块名（规范名 + 中文别名） | 无 |
| `载入Python模块(模块名)` | 载入白名单模块，返回不透明句柄 | 文本 |
| `调用Python函数(句柄, 函数名, ...参数)` | 调用白名单函数或读取白名单常量 | 句柄、文本、任意个安全参数 |

示例：

```
定义 m = 载入Python模块("math")
定义 r = 调用Python函数(m, "sqrt", 16)     # 4.0
定义 p = 调用Python函数(m, "pi")           # 3.141592653589793

定义 j = 载入Python模块("json")
定义 d = 调用Python函数(j, "loads", "{\"a\": 1}")
```

也支持中文别名：`"数学"`、`"统计"`、`"正则"`、`"哈希"`、`"网址解析"` 等。

## 可用模块

`math`、`json`、`statistics`、`collections`、`itertools`、`functools`、`re`、
`datetime`、`pathlib`、`hashlib`、`base64`、`urllib.parse`（均含中文别名）。

每个模块还维护一份**属性白名单**，只有列在其中的函数/常量可访问，例如
`json` 仅开放 `dumps` / `loads`（不开放带文件 I/O 的 `load` / `dump`）。

## 安全模型

1. **静态导入**：白名单模块在包加载时用字面量 `import` 一次性导入；用户输入永远
   不会成为 `import` / `exec` / `eval` / `compile` 的参数。
2. **双层白名单**：模块名 + 模块属性都必须命中白名单；所有下划线属性（如
   `__import__`、`__builtins__`、`__class__`）无条件拒绝。
3. **不透明句柄**：`载入Python模块()` 返回的句柄只有下划线槽位，道语言的属性
   访问兜底逻辑会拒绝下划线成员，因此无法通过 `m.sqrt` 之类写法绕过桥。
4. **值转换隔离**：
   - 入站只允许空值、布尔、整数、小数、文本、字节、列表、元组、字典、集合；
     函数、模块、文件句柄等对象会被拒绝。
   - 出站对 `dict` / `list` / `tuple` 等做递归转换并保持类别；`None` 直通；
     `bytes` 保留为字节；`pathlib.Path` → 路径文本；`datetime` → ISO 文本；
     `hashlib` 哈希对象 → 十六进制摘要；`itertools` 迭代器 → 有上限物化的列表。
   - 文件/流句柄、模块、函数、类、代码对象等一律抛中文运行时错误，不泄漏引用。
5. **资源上限**：转换深度 ≤ 32，容器元素 ≤ 10000，迭代器消费 ≤ 10000，
   抵御深嵌套与无限迭代器造成的内存耗尽。
6. **错误本地化**：类型错误抛 `类型错误`，白名单/安全拒绝抛 `运行时错误`，
   Python 侧异常统一包装为中文 `运行时错误`。

## 已知限制

- 可调用对象不能跨越桥，因此 `functools.reduce` 虽在白名单中，但无法传入自定义
  归约函数；可在 Python 侧封装成专用函数后再加入白名单。
- `re.match` / `re.search` / `re.compile` 返回对象类型，未开放；可用
  `findall` / `sub` / `split` 等返回安全类型的函数替代。
- 迭代器会被物化为列表，不具备惰性；无限迭代器不在白名单内。
